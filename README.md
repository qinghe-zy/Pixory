# Pixory

当前版本：2.8.10（2026-10-24，Android）。推出 AI 交互式沙箱系统、推挤缩放式 3D 侧边栏、聊天视觉排版定制与认知级深度记忆演进。

## 把喜欢的角色、故事和资料，放在一段可以继续的陪伴里

Pixory 是一款有温度的本地数字记忆画卷。

你可以在这里创建角色、开始一段长期聊天、保存共同经历，也可以把图片、视频、文档和灵感整理到同一个主题里。聊天、记忆、分支和资料彼此连接，让每一次打开应用都能接着上一次继续。

## 你可以怎样使用 Pixory

### “我想和一个熟悉的角色长期聊天”

创建角色卡，写下角色的性格、背景、说话方式和第一句问候。每次聊天都会沿着这张角色卡继续，重要的共同经历也能慢慢沉淀下来。

### “我想保留每一条故事路线”

对某句话进行编辑、重新生成，或从某个瞬间开启另一条路线。原来的内容会继续留在记录里，你可以随时回到喜欢的版本。

### “我想让 AI 读懂我的世界观”

把设定集、小说资料、参考图片、视频和其他文档放进 Pixory，再把需要的资料交给指定聊天。回答可以带上材料来源，查找原文更方便。

### “我想把重要的共同经历留给以后”

你可以查看角色记住了什么，调整记忆内容和范围，保留值得长期使用的部分，也可以把暂时的想法收进单独的记录里。

### “我想把私密内容放在更安心的地方”

Personal 私密空间拥有独立的进入方式和内容区域。聊天、资料、图片和备份都可以在这个空间中单独整理。

### “我想把手机里的灵感整理起来”

批量导入图片和视频，为它们添加主题、分组、标签、备注和收藏。原始素材会作为独立文件保存，浏览时使用轻量预览，整理和查找都更轻松。

## Pixory 的核心体验

### 长期陪伴

每个聊天线程都有自己的角色、经历、资料和故事路线。打开旧线程时，可以从熟悉的地方继续。

### 可回看的记忆

记忆带有来源和使用范围。你能看到它来自哪段对话，也能在需要时编辑、确认、暂时搁置或移除。

### 资料与聊天相连

图片、视频、文档和 IP 资料可以成为聊天中的参考。资料按照主题整理，引用时能回到对应的文件和片段。

### 故事可以分叉

一次重新生成、一处历史编辑，都可以发展成新的分支。不同路线各自保留，适合角色扮演、小说推演和创意探索。

### 回复过程清晰可接续

AI 回复会逐步呈现。离开聊天、切到后台或暂时中断后，回到应用还能继续处理未完成的内容。

### 手机里的个人工作台

图片、视频、角色头像、文档、聊天附件和备份都能在手机中找到。搜索、收藏、最近查看和回收站帮助你持续整理个人资料。

## 一段典型旅程

~~~text
创建角色
  → 写下第一句问候
  → 开始一段聊天
  → 保存重要的共同经历
  → 添加图片、视频或设定文档
  → 为故事开启新的分支
  → 随时回来继续
~~~

整理一组素材时：

~~~text
选择图片、视频或文档
  → 放入主题或 IP
  → 添加分组、标签和备注
  → 收藏常用内容
  → 在需要的聊天中选择资料
  → 查看回答引用
~~~

## 主要功能

## 一、AI 对话与基础交互
1. **多模型接入与稳定流式体验**
   - 自由接入兼容标准 API 的大语言模型（如 DeepSeek、OpenAI、Claude、Gemini 等）。
   - 高稳定性流式生成引擎，支持切至后台保持生成、随时中断与无缝恢复。
2. **思考过程与富文本排版**
   - **推理过程呈现**：支持具备推理能力的大模型展示思考过程，折叠与展开平滑自然。
   - **专业排版与数学公式**：全面支持 Markdown 代码高亮、LaTeX 数学公式（行内与多行矩阵自适应排版）以及内联画廊图片展示。
3. **流畅的长会话与气泡操作**
   - 超长文本智能折叠与长列表流畅滑动，保障长对话稳定不卡顿。
   - 支持消息复制、全屏选词、单条编辑重发、收藏与便捷操作菜单。
4. **推挤缩放式侧边栏与交互体验**
   - 支持推挤缩放式（Push & Scale）与经典抽屉双模式切换，随滚动跟手自如，快速切换会话与配置。
   - 独立聊天视觉排版定制，支持多种配色主题、气泡圆角与字号微调。
   - 内置“AI 帮答”候选面板，支持短句与长句智能输入辅助。

## 二、长线记忆与时间线分支
1. **平行分支与路线回溯**
   - 对历史消息编辑或重新生成时，自动生成平行分支路线，旧版本完整保留。
   - 提供可视化分支树，主线进度自动对齐，适合角色扮演、故事推演与灵感探索。
2. **认知级记忆演进闭环**
   - **智能偏好捕捉**：自动识别日常对话中的喜好偏好、身份事实与重要经历，过滤即时闲聊寒暄。
   - **记忆动态迭代**：长期未引用的冗余信息自动降权，避免机械复读；同类碎片记忆聚合沉淀为深层画像，让角色越聊越懂你。
3. **全局检索与收藏穿梭**
   - 支持对关键回复一键收藏，与当前分支自动绑定。
   - 支持全文精准与模糊搜索，快速穿梭回特定对话时空。

## 三、深度陪伴与运行时系统
1. **人设定义与角色卡**
   - 自由创建和管理角色卡，自定义性格、世界观背景、专属问候语与独立头像。
2. **角色日常回溯（专属日记）**
   - 后台梳理日常深度对话互动，以角色口吻生成带有情感温度的专属日记。
3. **离线思绪与内心独白**
   - 本地捕捉对话情绪起伏，在幕后自主生成私密独白，用户可查阅并自主决定是否纳入后续对话。
4. **离线梦境生成**
   - 基于相处经历在空闲时发散生成角色风格的梦境片段，丰富陪伴的立体感。

## 四、知识挂载与本地 RAG 检索
1. **多格式文档知识库**
   - 支持导入 Markdown、PDF、DOCX、TXT 等多种格式，本地自动切片与向量化管理。
   - 可按主题（IP）或会话灵活挂载，充当大模型的背景世界观与资料库。
2. **防幻觉与精确引用溯源**
   - 多路混合检索增强生成，回复内容附带严格的文献引用标记，随时回溯原文出处。
3. **结构化查询与设定固化**
   - 支持对表格数据进行本地精确结构化查询。
   - 聊天中的关键短设定可一键固化存入资料库，注入提示词稳定区享受缓存加速。

## 五、AI 交互沙箱与创意制品
1. **轻量交互与即时运行**
   - 支持在对话中直接运行 2D 小游戏、WebGL/Three.js 交互动效、物理模拟、图表及独立网页。
   - 代码流式生成时以极简取景器占位，生成完毕即刻呈现交互画面，告别大段代码刷屏。
2. **沉浸全屏与单例调度**
   - 支持一键进入全屏沉浸畅玩，支持横竖屏自适应与代码实时微调。
   - 全局单例调度机制，确保运行流畅省电、低内存占用。
3. **纯净独立导出**
   - 制品支持导出为 100% 纯净独立的单文件 HTML，无水印、无外壳，电脑或手机浏览器双击即可离线运行。

## 六、视觉资产：导入与查重
1. **极速与无损海量导入**
   - 支持跨平台图片、视频混合批量导入，原文件物理拷贝，完整保留原始画质与 EXIF 信息。
   - 支持系统级删除确认（导入后清理原相册），保护素材安全。
2. **双重智能查重拦截**
   - **精确哈希查重**：文件级哈希极速比对，过滤完全一致的文件。
   - **感知视觉查重**：提取视觉特征，精准揪出分辨率不同或轻度裁剪的重复图片。

## 七、视觉资产：浏览与沉浸体验
1. **超清图片阅读器**
   - 高性能大图滑动与缩放，平滑流畅，自动记忆退出浏览位置。
2. **沉浸式短视频体验**
   - 顺畅的手势滑动浏览，视频快速预载秒开，支持 0.5×~3.0× 保音高变速播放。

## 八、视觉资产：整理与全局检索
1. **三级结构化收纳**
   - “全局 IP - 分组 - 标签”三层层级，标签根据使用习惯智能推荐。
2. **批量管理与全局检索**
   - 支持多选批量更改分组与标签；支持按 IP、标签多维筛选，支持按时间树折叠查看。
3. **安全回收站**
   - 采用安全软删除机制，误删可一键还原，彻底清理需用户二次确认。

## 九、双重空间与极致隐私
1. **物理隔离的双空间系统**
   - 拥有“普通空间”与“私人空间”，两者拥有完全独立的 SQLite 数据库与物理存储目录。
2. **严苛的门禁保护**
   - 支持图案锁、指纹/面容解锁以及自定义安全恢复密钥。
3. **落锁即时清理**
   - 私人空间锁定后，瞬间释放内存图片缓存与任务上下文，确保私密数据安全。

## 十、数据主权与存储掌控
1. **全量无损备份与恢复**
   - 支持一键完整打包数据库、原图、视频、附件及角色资产，支持跨设备无损还原。
   - API 密钥仅保存在系统硬件安全区（SecureStore），不随备份文件导出。
2. **存储透视与清理**
   - 直观展示原图、缩略图、缓存与回收站的存储用量，支持一键释放冗余空间。
3. **用量与缓存透明化**
   - 详尽统计模型请求量与 Token 消耗，支持提示词缓存（Prompt Cache）命中分析。
4. **系统级外部内容捕获**
   - 深度集成系统级分享接口，随时从相册或其他应用直接投递素材至 Pixory。

## 资料如何留在你的设备里

Pixory 将聊天记录、角色、记忆、标签和资料目录保存在设备中。图片、视频、文档、头像和备份使用应用管理的文件空间，浏览预览与原始文件分开保存。

AI 聊天时，应用会根据你选择的角色、聊天、记忆和资料整理本轮内容，并发送给你配置的模型服务。模型服务商和密钥由你自行选择与管理。

## 安装 Pixory

### 设备建议

- Android 10 / API 29 及以上
- 建议 4 GB 或更高运行内存
- 根据个人资料数量预留充足存储空间
- AI 聊天需要可用网络和模型服务配置

### 安装步骤

1. 从[官网下载区](https://mist01.com/#download)获取安装包。
2. 在 Android 设备上完成安装。
3. 首次导入图片、视频或文档时，根据系统提示选择所需权限。
4. 在设置中添加模型服务和对应密钥。
5. 创建一个角色，发送第一条消息。

## 参与开发

Pixory 使用 Expo、React Native 和 TypeScript 构建，面向 Android 持续开发。项目将本地数据、移动端页面、AI 能力和媒体管理放在同一个应用体验中。

### 环境

- Node.js
- pnpm
- Android Studio、Android SDK
- Expo 54 对应开发环境

### 安装与启动

~~~bash
pnpm install
pnpm start
pnpm android
~~~

### 常用检查

~~~bash
pnpm run typecheck
pnpm test
pnpm run doctor
~~~

docs/         使用指南、产品资料和网站内容
tests/        自动化测试

~~~
