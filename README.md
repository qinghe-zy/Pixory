# Pixory

## 把喜欢的角色、故事和资料，放在一段可以继续的陪伴里

Pixory 是一款 Android 优先的本地陪伴式 AI 应用。

你可以在这里创建角色、开始一段长期聊天、保存共同经历，也可以把图片、视频、文档和灵感整理到同一个主题里。聊天、记忆、分支和资料彼此连接，让每一次打开应用都能接着上一次继续。

## 你可以怎样使用 Pixory

### “我想和一个熟悉的角色长期聊天”

创建角色卡，写下角色的性格、背景、说话方式和第一句问候。每次聊天都会沿着这张角色卡继续，重要的共同经历也能慢慢沉淀下来。

### “我想保留每一条故事路线”

对某句话进行编辑、重新生成，或从某个瞬间开启另一条路线。原来的内容会继续留在记录里，你可以随时回到喜欢的版本。

### “我想让 AI 读懂我的世界观”

把设定集、小说资料、参考图片、视频和其他文档放进 Pixory，再把需要的资料交给指定聊天。回答可以带上材料来源，查找原文更方便。

### “我想把重要的共同经历留给以后”

你可以查看角色记住了什么，调整记忆内容和范围，保留值得长期使用的部分，也可以把暂时的想法收进单独的记录里。

### “我想把私密内容放在更安心的地方”

Personal 私密空间拥有独立的进入方式和内容区域。聊天、资料、图片和备份都可以在这个空间中单独整理。

### “我想把手机里的灵感整理起来”

批量导入图片和视频，为它们添加主题、分组、标签、备注和收藏。原始素材会作为独立文件保存，浏览时使用轻量预览，整理和查找都更轻松。

## Pixory 的核心体验

### 长期陪伴

每个聊天线程都有自己的角色、经历、资料和故事路线。打开旧线程时，可以从熟悉的地方继续。

### 可回看的记忆

记忆带有来源和使用范围。你能看到它来自哪段对话，也能在需要时编辑、确认、暂时搁置或移除。

### 资料与聊天相连

图片、视频、文档和 IP 资料可以成为聊天中的参考。资料按照主题整理，引用时能回到对应的文件和片段。

### 故事可以分叉

一次重新生成、一处历史编辑，都可以发展成新的分支。不同路线各自保留，适合角色扮演、小说推演和创意探索。

### 回复过程清晰可接续

AI 回复会逐步呈现。离开聊天、切到后台或暂时中断后，回到应用还能继续处理未完成的内容。

### 手机里的个人工作台

图片、视频、角色头像、文档、聊天附件和备份都能在手机中找到。搜索、收藏、最近查看和回收站帮助你持续整理个人资料。

## 一段典型旅程

~~~text
创建角色
  → 写下第一句问候
  → 开始一段聊天
  → 保存重要的共同经历
  → 添加图片、视频或设定文档
  → 为故事开启新的分支
  → 随时回来继续
~~~

整理一组素材时：

~~~text
选择图片、视频或文档
  → 放入主题或 IP
  → 添加分组、标签和备注
  → 收藏常用内容
  → 在需要的聊天中选择资料
  → 查看回答引用
~~~

## 主要功能

### AI 聊天

- 创建多个长期聊天线程
- 为每段聊天选择角色和模型
- 流式阅读、停止、继续和重新生成
- 搜索历史消息、收藏重要内容
- 从历史消息编辑并开启新分支
- 发送图片和文档作为本轮内容

### 角色卡

- 创建角色名称、背景、性格和说话方式
- 设置头像、第一句问候和备用问候
- 导入常见角色卡文件
- 为不同聊天保留独立的角色版本

### 记忆

- 查看角色已经记住的内容
- 按聊天、角色、主题或资料范围整理
- 编辑、确认、标记过期和移除记忆
- 通过来源回看记忆从哪里产生

### 故事分支

- 从任意消息开启新路线
- 保留原路线和新路线
- 切换路线继续聊天
- 查看消息版本和采用的路线

### 资料与 IP

- 创建角色、系列、项目或世界观主题
- 管理图片、视频、PDF、DOCX、Markdown 和 TXT
- 使用分组、标签、备注、封面和收藏整理内容
- 通过搜索、最近查看和回收站快速管理
- 在聊天中选择资料并查看引用

### 图片和视频

- 批量导入图片和视频
- 保留原始文件与完整尺寸
- 自动生成独立缩略图和视频封面
- 支持全屏浏览、播放、倍速和位置恢复
- 支持重复内容检查和批量整理

### Personal 私密空间

- 使用独立入口整理私密聊天和资料
- 支持密码、图案、恢复密钥和生物识别
- 手动或离开应用后锁定空间
- 单独备份和恢复私密内容

### 备份与迁移

- 导出聊天、角色、记忆、资料和原始素材
- 保留图片、视频、文档、头像和附件
- 通过文件校验帮助恢复完整关系
- 支持普通空间、单个主题和 Personal 空间的整理方式

## 资料如何留在你的设备里

Pixory 将聊天记录、角色、记忆、标签和资料目录保存在设备中。图片、视频、文档、头像和备份使用应用管理的文件空间，浏览预览与原始文件分开保存。

AI 聊天时，应用会根据你选择的角色、聊天、记忆和资料整理本轮内容，并发送给你配置的模型服务。模型服务商和密钥由你自行选择与管理。

## 安装 Pixory

### 设备建议

- Android 10 / API 29 及以上
- 建议 4 GB 或更高运行内存
- 根据个人资料数量预留充足存储空间
- AI 聊天需要可用网络和模型服务配置

### 安装步骤

1. 从[官网下载区](https://mist01.com/#download)获取安装包。
2. 在 Android 设备上完成安装。
3. 首次导入图片、视频或文档时，根据系统提示选择所需权限。
4. 在设置中添加模型服务和对应密钥。
5. 创建一个角色，发送第一条消息。

## 参与开发

Pixory 使用 Expo、React Native 和 TypeScript 构建，面向 Android 持续开发。项目将本地数据、移动端页面、AI 能力和媒体管理放在同一个应用体验中。

### 环境

- Node.js
- pnpm
- Android Studio、Android SDK
- Expo 54 对应开发环境

### 安装与启动

~~~bash
pnpm install
pnpm start
pnpm android
~~~

### 常用检查

~~~bash
pnpm run typecheck
pnpm test
pnpm run doctor
~~~

### 目录速览

~~~text
src/          应用页面、AI 能力、资料和数据服务
android/      Android 原生工程
docs/         使用指南、产品资料和网站内容
tests/        自动化测试
scripts/      检查、基准和发布脚本
~~~
