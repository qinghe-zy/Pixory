# Pixory 用户故事与验收标准

> 适用版本：v2.8.5 稳定基线  
> 文档状态：交付与回归基线  
> 关联 PRD：[`产品PRD-Pixory-稳定版-v2.8.5.md`](./产品PRD-Pixory-稳定版-v2.8.5.md)

## 1. 使用说明

- **优先级**：P0 为稳定版本硬门禁，P1 为应交付能力，P2 为后续增强。
- **状态**：已实现、部分实现、待验证、规划、实验/不上线。
- 验收必须覆盖主流程、空状态、错误、取消、后台、返回、重复操作和隐私空间边界。
- “已实现”表示代码和主要业务闭环存在；未完成真机或端到端验证的故事仍需标记“待验证”。

## 2. 角色

| 角色 | 说明 |
| --- | --- |
| U1 长期陪伴用户 | 反复进入同一角色和线程，希望关系连续 |
| U2 创作用户 | 使用角色卡、分支、材料和日记/梦境进行创作 |
| U3 材料整理用户 | 管理 IP、图片、视频、文档、标签和备份 |
| U4 隐私用户 | 使用 Personal 空间处理敏感内容 |
| U5 维护人员 | 需要诊断、发布、回滚和版本追踪 |

## 7. 回归清单

每个稳定版候选至少执行：

- 新建线程 → 发送文本 → 流式回复 → 停止/重试 → 重新进入。
- 编辑消息 → 创建分支 → 切换分支 → 搜索 → 收藏 → 返回定位。
- 创建角色 → 导入角色卡 → 临时会话保存为新卡 → 重新开线程。
- 写入记忆 → 查看来源 → 忽略/撤销 → 验证上下文不再注入。
- 导入图片/视频/文档 → 生成缩略图 → 检索/引用 → 软删除 → 恢复/清空。
- normal ↔ personal 锁定/解锁 → 后台任务 → 跨空间移动 → 备份/恢复。
- 应用后台、路由切换、网络失败、Provider 失败、进程重启后的恢复。
- 空状态、无结果、权限拒绝、磁盘不足、文件缺失、重复导入和取消操作。
