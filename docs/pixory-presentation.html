导入门禁探测（Commit Budget Gate）

共享总量 1000 实体 / 256MB 单文件 / 32GB 批次余量校验，在文件 I/O 前早拒绝，防爆盘。

2

4-Worker 有界并发与原件隔离拷贝

原文件完整拷贝至应用私有目录，永不压缩、永不裁剪、永不覆写；独立异步生成 320px 缩略图。

3

SQLite FTS5 微秒级全文索引建立

基于 N-Gram 自动切词，为素材标签、分组、备注建立倒排索引，250ms 防抖极速全文检索。

4

软删除生命周期与 Manifest V2 备份

删除素材默认移入回收站支持随时恢复；备份包覆盖原文件、数据库与元数据，排除敏感密钥。

Personal 私密空间物理双沙盒机制

03 / BIFURCATED MEMORY

双模长效记忆治理体系：拟人心智 vs 严谨工程

打破成熟软件黑盒弊端，严格区分日常情感陪伴与严肃推演的记忆生命周期

伴聊 IM 模式 拟人心智模型（模拟人类遗忘与生活沉淀）
  • “六记六不记”准入筛网：坚决拦截“洗澡、拿外卖、吃撑了”等瞬态生理动作与垫话，拦截率达 95%，源头杜绝“偷窥狂式记忆”。
  • 三车道生命周期流转：
    • Working：临时观察车道，新事实先沉淀观察；
    • Confirmed：跨会话多轮印证或用户确认，核心画像（过敏/生日）锁死 0.6 衰减铁底永不遗忘；
    • Archive：连续 5 次注入未被采纳触发 ACT-R 负反馈自动归档。
  • MMR 多样性重排：压制同类记忆堆叠，彻底根除刚聊完就机械复读的“祥林嫂”困扰。
  • 夜间手账日记反哺：白天短聊碎片深夜提炼为伴侣手账，次日生成 TopicHook 自然开场。
长聊 Pro 模式 严谨工程记忆（严肃创作、知识推演与防伪）
  • 人工锁定快照（Confirmed Snapshot）：世界观核心设定集人工置顶锁定，无自然衰减，永久绝对生效。
  • 端侧混合检索（Hybrid RAG）：SQLite FTS5 BM25 词面初筛 + 向量 RRF 融合重排，离线基准测试命中率达 88.4%。
  • 确定性 SQL 检索（零幻觉）：遇到 CSV/Excel 表格，自动转为 SQLite 临时表只读 SQL 查询，复杂数据绝对零幻觉。
  • 句子级引用溯源（Citation）：模型回答带 [S1] 引用角标，反向校验 SHA-256 签名，点击直达本地文档出处。
  • Git-like 分支作用域隔离：记忆与摘要严格挂载在当前分支树，不同剧情推演路线绝不串味。

四种生活负荷自知觉（Living State）

3

夜间勿扰守卫（DND Guard）

23:30 ~ 07:00 期间系统自动进入静音休眠，除非用户明确要求（如“明早六点叫我”），绝不半夜惊醒用户。

  • 情境感知避让（Situational Delay Guard）：识别用户“去洗澡”延后 25~35m，说“开会”延后 45~60m。
  • 模型自主留白权：话题自然结束时输出 [NEXT_FOLLOWUP: pass]，伴侣自觉保持安静守护。

07 / DOCUMENT AGENT

智能文档 Agent 与 Word/PDF 差量原位手术

突破大模型修改文档全量重写瓶颈，实现企业级办公公文的“动口即改、原位留痕”

13ms OOXML 游标 公章表格字节守恒 Diff 留痕对比
差量手术与半开区间字节守恒原理
  • 传统重写的三大灾难：改动 20 页报告的一句话，全文重写需等 2 分钟、浪费几万 Token，且红头公章、表格格式极易丢失。
  • DOCUMENT_PATCH 差量补丁协议：约束模型只吐出修改段落的 Diff 补丁，未提及章节一个字都不重吐。
  • 端侧纯 JS 13ms 游标手术：Word 本质是 XML 压缩包。端侧基于纯 JS 游标双指针扫描，13ms 定位目标 <w:p>。
  • 跨 Run 虚拟文本双向投影：在内存中将分散的样式标签平铺为单行文本，替换文字后精准反向映射。
  • 半开区间字节守恒（保护公章表格）：公章 <w:drawing> 与表格 <w:tblGrid> 100% 字节原样保留。
  • CAS 直连存储池：单条元数据 <1KB 指针入库，彻底切断大 Base64 膨胀爆库路径。

08 / VIEWPORT DYNAMICS

双泳道流式渲染与超长会话视口防抖工程

1

思考流与正文双泳道解耦

将思考过程（Reasoning）与正文输出分入两个独立渲染表面，思考框折叠展开绝不引发正文树重构重排。

2

300 字符量化步长与 ±4dp 稳定器

不随单个字符动态重算高度，固定上限 7 行（161px），首尾 24dp 渐变遮罩，文字平滑卷动，彻底根除跳行抖动。

3

单阶段原子展开锁（Single-stage Expand Lock）

展开时先锁定滚动视口，待全量文本后台一次性原生测量完成后展开，杜绝两阶段测量导致的视口位移跑飞。

原生视口维持与海量历史加载
  • 原生视口维持（Maintain Visible Position）：设定阈值 250，向上翻看历史时屏幕物理钉死不动，新字屏幕外静默渲染，彻底根除吸底与剧烈震颤。
  • EMA 速率打字机平滑引擎：指数移动平均预估吐字速率，网络断流时以 0.6~1.0 字符/帧平稳滑行，绝不卡死急停。
  • Keyset 复合游标 O(n) 合并：抛弃慢查 OFFSET/LIMIT，采用 (createdAt, id) 游标实现单次有序归并。
