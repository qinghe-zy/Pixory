# 方案一提示词：「霓彩剧场」NEON THEATRE

## 设计哲学宣言

这套视觉系统的核心命题是：**一家真正相信本地隐私权的 AI 产品，它的官网不应该和所有硅谷 SaaS 长得一样。** 它应该像一张精心设计的艺术演出海报，充满主张、充满个性，让人一眼就记住它在宣布什么。

灵感来源是 1990 年代日本先锋剧场的视觉宣传体系——那些由田中一光、横尾忠则设计的表演海报：大胆的撞色块、强势的字体排印、戏剧性的层次结构、压迫感与空气感并存的留白节奏。这是艺术字风格的完全释放，用鲜明的色彩和强势的版式替代常见的渐变/毛玻璃套路。

## 一、色彩体系（完整定义）

### 主色调策略：Full Palette（4 色命名角色）

| 角色名 | 颜色名 | HEX | OKLCH | 使用场景 |
|---|---|---|---|---|
| Canvas（画布） | 深煤黑 | `#0E0C0A` | `oklch(8% 0.005 60)` | 页面背景，不是纯黑，带一丝极暗的暖褐底调，像被碳化的纸 |
| Primary（主色） | 霓虹洋红 | `#FF2D78` | `oklch(62% 0.28 355)` | 最重要的按钮、英雄区主标题下划线、鼠标悬浮高亮、圆点 badge |
| Secondary（辅色） | 电光柠檬 | `#E8FF00` | `oklch(95% 0.28 108)` | 章节序号、kicker 标签底色、关键词填充色、装饰性线条 |
| Accent（点缀） | 冷青白 | `#C8F0FF` | `oklch(94% 0.04 212)` | 正文辅助、nav 链接、描述文字，给整体降温用 |
| Surface（表面） | 深石板灰 | `#1A1714` | `oklch(14% 0.008 50)` | 卡片背景、功能模块背景色，比 Canvas 亮一级 |

### 字色体系

- **正文主字**：`#F5F0E8`（暖白，不刺眼）
- **次要描述文字**：`#8C8578`（暖灰）  
- **被强调的关键词**：Primary 霓虹洋红 `#FF2D78` 或 Secondary 电光柠檬 `#E8FF00`

### 毛玻璃定义（此方案中的精确用法）

毛玻璃**只用于导航条一处**，其他位置不用，因为本方案整体是实色块语言，毛玻璃滥用会破坏戏剧感。

**导航条毛玻璃规格：**
- `background: rgba(14, 12, 10, 0.6)` — 深色毛玻璃，60% 透明度
- `backdrop-filter: blur(24px) saturate(140%)` — 模糊值 24px，同时增加饱和度 140%，让后面内容的颜色透过来时更鲜艳
- `border-bottom: 1px solid rgba(255, 45, 120, 0.15)` — 底边框用主色霓虹洋红调成极淡的边线，增加精致感
- **hover 状态不改变毛玻璃**，只改变导航链接文字颜色

## 二、字体系统（艺术字优先）

### 主字体：Bebas Neue（Google Fonts 免费）
- **用于**：英雄区主标题、章节大序号、各功能模块标题
- **尺寸**：英雄标题 `clamp(88px, 12vw, 160px)`，功能标题 `64px`
- **字重**：400（Bebas Neue 本身只有这一个字重，全大写，每个字母都像一块切割的混凝土）
- **颜色**：纯白 `#F5F0E8`，但关键词单独变色为霓虹洋红
- **字距**：`letter-spacing: 0.05em`（轻微拉开，增加海报气质）
- **行高**：`line-height: 0.92`（压缩，让标题块更有密度）

### 副字体：Syne（Google Fonts 免费）
- **用于**：副标题、Kicker 标签、导航文字、正文功能描述
- **尺寸**：副标题 `24px`，kicker `11px`，正文 `16px`
- **字重**：正文 400，副标题 700，kicker 800（极粗，全大写）
- **Syne 的特点**：它有一种类似 Eurostile 的几何气质，字母内空间不规则，比 Inter 更有个性，适合设计圈/技术圈产品

### 点缀字体：Playfair Display Italic（Google Fonts 免费）
- **用于**：报价、引用块、「记忆」「梦境」等诗意词汇的斜体强调
- **字号**：`24-32px`，斜体使用
- **颜色**：Secondary 电光柠檬 `#E8FF00`，在深色背景上极为夺目
- **出现位置**：仅在「深度记忆」功能模块中的一句话引用，以及页脚 slogan 处使用

## 四、区域一：导航条（Position: Fixed, top: 0）

**尺寸：** 高度 72px，宽度 100vw  
**背景：** 毛玻璃，规格见上方定义  
**布局：** Flex，两端对齐

**左侧 Logo 区块：**
- 文字 `PIXORY` 使用 Bebas Neue，字号 `28px`，颜色 `#F5F0E8`
- Logo 文字左侧有一个实心圆形，直径 `10px`，颜色霓虹洋红 `#FF2D78`，带 `box-shadow: 0 0 8px rgba(255, 45, 120, 0.8)` 的辉光效果（模拟霓虹灯管）
- Logo 文字和圆点之间间距 `10px`

**中间导航链接组（三个）：**
- `Engine` / `Memory` / `Privacy`
- 字体 Syne，字号 `13px`，字重 `600`，全大写，字距 `0.1em`
- 默认颜色 `rgba(245, 240, 232, 0.5)`
- **Hover 交互**：颜色变化为 Secondary 电光柠檬 `#E8FF00`，同时文字下方出现一条 `2px` 高的实心线（颜色同 Primary 洋红），从左向右滑入，动画时长 `250ms`，缓动 `ease-out`

**右侧按钮：「阅读文档」（高优先级）**

> 🎯 这是用户明确要求的核心入口按钮，设计为全场最显眼的元素之一。

- **按钮文字**：`阅读文档 / Docs`（中英双行，英文为 Syne 细字，中文为粗体）
- **按钮尺寸**：宽 `140px`，高 `44px`，圆角 `4px`
- **按钮样式**：
  - 默认状态：背景 Secondary 电光柠檬 `#E8FF00`，文字颜色深煤黑 `#0E0C0A`，字体 Syne 700
  - 这个亮黄色的实心按钮在整个深色毛玻璃导航条中会形成极强的视觉锚点，任何视线扫过导航条都会被它抓住
- **Hover 交互**：
  - 背景变化到霓虹洋红 `#FF2D78`，文字颜色保持 `#0E0C0A`（深色，保证对比度）
  - 同时出现 `box-shadow: 0 0 20px rgba(255, 45, 120, 0.6), 0 4px 12px rgba(255, 45, 120, 0.3)` 的双层辉光
  - 按钮整体 `transform: translateY(-2px) scale(1.02)`，轻微上浮感
  - 动画时长 `300ms`，缓动 `cubic-bezier(0.16, 1, 0.3, 1)`（Expo Out，手感极好）
- **Click/Active**：`transform: translateY(0) scale(0.98)`，有按下感

**右侧次按钮：「下载 Android」**
- 紧贴阅读文档按钮左侧，间距 `12px`
- 样式：透明背景 + `1px solid rgba(245, 240, 232, 0.3)` 描边，文字颜色 `#F5F0E8`，字体 Syne 600，字号 `13px`
- Hover：描边颜色变为霓虹洋红，文字颜色变为霓虹洋红，无辉光效果（和主按钮产生层级差）

## 五、区域二：英雄区（Hero Section）

**尺寸：** 高度 `100vh`，内容左对齐

**背景处理（这是整套设计的核心艺术表达）：**
- 背景底色 Deep Coal `#0E0C0A`
- 在页面右侧三分之二区域，放置一个由纯色实色块构成的抽象几何构图：
  - 一个大的正方形色块，尺寸约 `520px × 520px`，颜色为 Secondary 电光柠檬 `#E8FF00`，`opacity: 0.08`，绝对定位在视口右上方，轻微旋转 `rotate(-15deg)`，这是整个背景最大的结构元素
  - 叠加其上一个更小的正方形，尺寸约 `200px × 200px`，颜色霓虹洋红 `#FF2D78`，`opacity: 0.15`，位置在大正方形的右下角区域，旋转 `rotate(8deg)`
  - 一条粗横线，高度 `4px`，宽度 `180px`，颜色电光柠檬 `#E8FF00`，`opacity: 0.4`，在大色块左侧
- **不使用任何渐变**：所有背景元素都是实色几何块，靠透明度和叠加产生关系，这是海报美学的基础语言

**英雄区文字内容（从上到下）：**

第一层：Kicker 标签
- 字体：Syne 800，字号 `11px`，全大写，字距 `0.25em`

- 位置：距离顶部 `180px`（导航条 72px + 间距 108px）

第二层：主标题（两行，Bebas Neue）
- 字号：`clamp(88px, 11vw, 152px)`
- 行高：`0.92`，让两行紧密贴合，形成一个强大的文字块
- 第一行文字：`STORIES THAT`，颜色 `#F5F0E8`（纯白）
- 第二行文字：`STAY.`，颜色 Primary 霓虹洋红 `#FF2D78`
- 两行文字之间有一条 `3px` 实线，颜色 Secondary 电光柠檬 `#E8FF00`，宽度等同第一行文字宽度，将两行视觉上分割又连接

第四层：主行动按钮组
- 与描述文字之间距离 `48px`
- 主按钮「探索数字档案室」：
  - 背景霓虹洋红 `#FF2D78`，文字 `#0E0C0A`，Syne 700

## 十一、滚动入场动效规格

所有内容区块默认 `opacity: 0, transform: translateY(30px)`，通过 IntersectionObserver 触发时：
- 过渡到 `opacity: 1, transform: translateY(0)`
- 时长 `800ms`，缓动 `cubic-bezier(0.16, 1, 0.3, 1)`（Expo Out）
- 同一区块内多个元素，`stagger` 间距 `100ms`

英雄区主标题入场：
- 两行标题分别从 `translateY(100%)` 掉落（文字从遮罩下方入场），`overflow: hidden` 包裹
- 第一行动画时长 `900ms`，第二行延迟 `120ms`
- Kicker 从 `opacity: 0` 到 `opacity: 1`，延迟 `200ms` 后触发

导航条入场：
- 页面加载后 `300ms` 延迟，从 `translateY(-100%)` 到 `translateY(0)`，时长 `600ms`，`ease-out`
