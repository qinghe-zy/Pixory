Pixory 是一款 Android-first、本地优先的 IP 图片资产管理工具。它不压缩、不裁剪，将原图、语境与判断，留在同一个私人秩序里。

放弃复杂的云端同步与社交功能，回归工具的本质。

01 / 收束

以 IP 为维度的归档体系

每一个 IP 都是一个独立的视觉宇宙。支持角色、视觉识别、主题、品牌图像或创意系列的深度整理，让图片资料真正沉淀为结构化的项目册。

02 / 原图

无损保存，本地绝对可靠

严格遵循本地优先原则。导入的图片直接复制到应用的私有存储，不压缩、不裁剪、不改变原始编码。这不只是一个相册，而是一个可以信赖的素材金库。

03 / 回声

分组、标签与软删除

建立轻量级的归类组（如季节、场景、节庆）。通过自定义标签与详尽的备注系统找回记忆线索。支持软删除（回收站机制），避免因误触造成不可挽回的资产损失。

Capabilities

清晰、干脆的能力矩阵。

批量稳定导入

一次性选中多张图片，自动复制原图、生成缩略图、写入 SQLite 并赋予分类，过程平滑无感。

SQLite 结构化数据

一切元数据（宽、高、尺寸、MIME 类型、收藏状态、笔记）都井井有条地存储于本地 SQLite 数据库中。

原图级备份

备份导出不仅仅是缩略图。一次导出，包含完整的数据库、原图文件夹和 Manifest 文件，真正拥有你的数据。
