Archive Ethics

原质完整进入，缩略只做预览。设备内成库，离线可用。数据主权永远属于你。

01 / 质量不减

不为了节省空间而裁剪、二次压缩原始图像。你存入的，就是未来的母版。

02 / 离线本地

所有结构化数据保存在本地 SQLite 数据库中。无需网络，没有云端绑架。

03 / 开放带走

支持全量带走。原文件、缩略图、数据库清单一键迁移，毫不设限。

Workflow & Order

重建视觉秩序。

依靠 IP、分组、标签和备注的交叉索引，无论你的库有多大，总能在 3 秒内找到那张图。

  • Batch Import

    系统自动抽帧与生成缩略图，大批量进入缓存区。

  • Cross Indexing

    支持多个标签叠加检索，快速过滤非相关内容。

  • Soft Delete

    缓冲池机制，只有在清空回收站时才会发生真正的物理擦除。

// Pixory Core Architecture
import { LocalStorage, SQLite } from '@pixory/engine';

const archive = new LocalStorage({
  /* Never compress originals */
  preserveOriginals: true,

  /* SQLite for fast indexing */
  database: SQLite.connect('pixory.db'),
});

async function importAsset(file) {
  // 1. Copy original file untouched
  await archive.copy(file);

  // 2. Generate lightweight thumbnail for UI
  const thumb = await generateThumbnail(file);

  // 3. Store structured metadata
  return archive.database.insert({
    original: file.path,
    thumbnail: thumb.path,
    checksum: file.hash()
  });
}
