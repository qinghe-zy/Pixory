ACT I COGNITIVE LANES & CQRS ARCHITECTURE

意识的三重水流：记忆多车道流转

“寻常 AI 对话聊过百轮便言语混乱；Pixory 采用命令查询职责分离（CQRS），让思绪在三条车道各安其所。”

LANE 01 // 暂存车道

流动的即时工作台 · Working Lane

承载当下的短期对白、刚萌生的微妙情绪以及瞬时状态。此处数据高频擦写、敏捷共振，保留当前对话的鲜活感，但绝不直接污染稳固的长期知识库。

容积上限最近 20~50 轮对话
写入延迟Zero ms · 内存态
LANE 02 // 确信车道

凝结的事实与羁绊 · Confirmed Lane

只有经由用户反复确认、或是经由情感升华的事实（你的口味习惯、特别的纪念日、对艺术的偏好），才会通过认知提炼沉淀为确信语义网络，持久稳定。

提炼媒介语义萃取 & 矢量嵌入
防幻觉纠偏SQLite Vector Strict
LANE 03 // 归档车道

岁月封存的深层潜意识 · Archive Lane

数月前的旧事退居静默归档层。当夜幕降临、设备闲置时，离线梦境与思绪引擎在此自主生成「角色日记」与「长程回忆索引」，在被唤醒时按需重构。

潜意识机制离线梦境生成 (Idle Sleep)
存储介质无损物理全量压缩
✦ 命令与查询职责分离（CQRS）：读写分离，确保万轮对话不溢出、不降速、不崩坏

ACT III THE DUAL REALM & CRYPTOGRAPHIC SANCTUARY

双空间物理结界：两套数据库与绝对遗忘

我们拒绝虚浮的软件层权限糊弄。Pixory 在移动端存储底层划分「普通空间」与「私密空间」双轨架构，双套独立 SQLite 物理文件，由不同密钥单独锁闭。

REALM I · NORMAL 日常陪伴视界

日常显露空间

  • 数据库载体 pixory_default.sqlite
  • 检索引文范围 日常对白 & 公开归档

ACT IV PERPETUAL LOSSLESS ARCHIVE

永恒资料库与无损视觉方舟

“云端服务常常悄无声息地压缩你珍贵的照片；而在 Pixory，比特流的纯粹原貌被视为神圣的记忆财产。”

SPEC 01 // FIDELITY

原图原画，零二次压缩

无论是高达 8K 的摄影原作、未剪裁的 LivePhoto，还是数十兆的专业原画，Pixory 均采用物理无损字节流封存，拒绝任何云端式画质剥削。

• 保留 EXIF 元数据与真实色域档案 (DCI-P3 / AdobeRGB)
SPEC 02 // DEDUPLICATION

双层哈希查重机制

结合 SHA-256 比特级精确摘要与 pHash 视觉感知哈希算法。即使同一张图片被微调尺寸或保存为不同格式，系统亦能精准辨识并避免冗余占用。

• SHA-256 物理比对 + 均值感知哈希双轨并行校验
SPEC 03 // PORTABILITY

Manifest V2 自主归档与迁移

不搞专有格式壁垒绑架用户。一键导出标准 JSON + 原生 SQLite 归档包，所有角色人格卡、历史记忆链条与相册数据均支持无缝随身携带。

• 开放标准规范，哪怕三十年后亦能用通用工具解包
