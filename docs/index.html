Release Notes

稳定。清晰。耐用。更新不是喧哗，是秩序继续变清楚。

2026-06-24

Version 2.5.1

同版本 OTA 热修

2.5.1 发布后追加推送了同版本热更新，补齐外部 txt/md 在解析不足时的模型辅助结构恢复，并把导入评审结果显式分流到 summary、profile 和 formal memory。

连续性导入

支持把 Pixory 原生续聊包直接接回，也支持把其他平台整理出的迁移文档导回当前线程，继续沿着角色与分支上下文聊天。

记忆审读门禁

外部导入内容先做结构提取，再交给记忆模型审读和验收；可解析消息会渲染到聊天页，其余压缩内容也会走审读后再进入后续记忆链路。
