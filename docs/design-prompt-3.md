# 方案三提示词：「碧岩熔金」JADE & GOLD

## 设计哲学宣言

这套视觉系统的核心命题是：**本地记忆不是冷冰冰的数据库，它是你亲手在数字世界里铸造的一块琥珀，将所有珍贵的东西封存其中，亿万年不褪色。**

设计灵感来自两个完全不同的领域的撞击：一是宋代官窑的青瓷釉色——那种不艳不俗、内敛却震慑人心的「粉青色」；二是文艺复兴时期珍宝馆（Kunstkammer）的展柜布局——精致的木格子、金箔边线、每一件藏品都有自己的位置和身份。

这是一套**明亮**的浅色系页面，打破所有 AI/科技产品默认的深色背景惯例。背景是极淡的、带玉质感的青白色，配以金色（不是廉价的金，而是冷调的铂金）作为主行动色，以深茶色为主文字色。这个调色板会让 Pixory 在一排深色 AI 应用中脱颖而出，像一块真正的美玉。

这是一套有主张的选择：在竞争对手都在说「我们有多暗、多神秘、多科技感」的时候，Pixory 用「我们有多珍贵、多持久、多可信赖」来回答。

## 一、色彩体系（完整定义）

### 主色调策略：Committed（一种饱和色统治 40-60% 的面积）

| 角色名 | 颜色名 | HEX | OKLCH | 使用场景 |
|---|---|---|---|---|
| Celadon（青瓷主色） | 粉青玉 | `#A8D8CF` | `oklch(83% 0.07 180)` | 英雄区大背景色块、区域分隔带背景、关键功能卡高亮背景 |
| Obsidian（深玄色） | 漆黑茶墨 | `#1C1917` | `oklch(12% 0.006 60)` | 主文字色、主按钮背景（在浅色背景上） |
| Gold（冷金色） | 铂金 | `#C8A84B` | `oklch(72% 0.11 80)` | 「阅读文档」主按钮、星级装饰、序号、特别强调词填充 |
| Chalk（白粉） | 贝壳白 | `#F7F4EE` | `oklch(97% 0.008 80)` | 页面主背景，带极微弱的暖调，非纯白 |
| Stone（石板灰） | 温灰 | `#7A7670` | `oklch(52% 0.012 60)` | 次要文字、描述文字、占位信息 |

### 补充色（非主色，极少量使用）

- **Blush（艳粉）**：`#E8657A`，`oklch(62% 0.18 10)`，只用于 Personal 隐私空间的标签和心形图标（情感性，非功能性）
- **Ink Blue（书墨蓝）**：`#2D4E7A`，`oklch(38% 0.1 260)`，只用于代码/命令行内的高亮文字

### 字色体系

- **H1/H2 标题**：Obsidian 漆黑 `#1C1917`
- **正文描述**：Stone 温灰 `#7A7670`
- **强调关键词**：Gold 铂金 `#C8A84B` 或 Celadon 粉青 `#A8D8CF`（深色背景上使用青瓷，浅色背景上使用铂金）
- **链接文字**：`#2D4E7A`（书墨蓝，传统超链接色调，有阅读文档类产品的亲切感）

### 毛玻璃定义（此方案中的精确规格）

本方案是浅色主题，毛玻璃的使用逻辑完全不同于深色方案——毛玻璃用于制造「玉器/水晶展柜」质感，而非「深空面板」质感。

**① 导航条毛玻璃（乳白半透明）：**
- `background: rgba(247, 244, 238, 0.80)` — 贝壳白 80% 不透明
- `backdrop-filter: blur(20px) saturate(180%)` — 模糊 20px，饱和度提升到 180%（让后方内容的颜色透过导航条时更加鲜艳浓郁，形成「棱镜」效果）
- `border-bottom: 1px solid rgba(168, 216, 207, 0.4)` — 底边用 Celadon 粉青调色，对应页面主色
- 这个导航条在滚动过视口内的粉青区域时，会透出青色调；在白色区域时，透出白色调，形成动态的色彩联动感

**② 「阅读文档」CTA 横幅的玉石展柜效果：**
- `background: rgba(168, 216, 207, 0.35)` — Celadon 粉青 35% 透明
- `backdrop-filter: blur(24px) saturate(160%)` — 较重的模糊，增强玉质深度感
- `border: 1px solid rgba(200, 168, 75, 0.4)` — Gold 铂金边框，像展柜的金属框架
- `box-shadow: 0 8px 40px rgba(168, 216, 207, 0.3), inset 0 1px 0 rgba(255,255,255,0.6)` — 外层青色阴影 + 内顶边的白色高光（模拟玉石反光）
- 圆角 `32px`

**③ 功能卡片的半透明玉质效果：**
- `background: rgba(255, 255, 255, 0.6)` — 白色 60% 透明
- `backdrop-filter: blur(12px)` — 轻度模糊
- `border: 1px solid rgba(168, 216, 207, 0.5)` — Celadon 边框，可见
- `box-shadow: 0 4px 24px rgba(168, 216, 207, 0.15), inset 0 1px 0 rgba(255,255,255,0.8)` — 外阴影 + 内顶边高光
- 圆角 `20px`

## 二、字体系统（艺术字优先，极具个性）

### 主展示字体：Canela（来自 Commercial Type，如无授权用 Ogg / DM Serif Display）
- **用于**：英雄区主标题、功能模块大字标题
- **字号**：`clamp(72px, 9vw, 128px)`
- **字重**：Light 300（Canela 的 Light 字重有极细的笔画对比和优雅的连字，像书法与排版的结合）
- **字距**：`-0.025em`
- **行高**：`1.0`
- **特殊处理**：标题中的关键词（如「记忆」「Yours」）使用 Gold 铂金 `#C8A84B` 的颜色，其余文字是 Obsidian 漆黑 `#1C1917`，通过颜色在长句中打出重音

> **免费替代方案**：Google Fonts 上的 **Playfair Display**（字重 300-400）或 **Cormorant Garamond**（Light Italic），二者都有类似的高对比衬线气质，但不在 Impeccable 禁用列表中（禁用的是这些字体作为「分类默认」的懒惰用法，但在有明确理由时可以使用；本方案使用 Playfair Display 的理由是：它的大字号衬线与「珍宝馆的标签卡片」这一视觉世界直接对应，而非因为「这是科技产品所以要用衬线体」）

### 副文本字体：Lausanne（来自 Swiss Typefaces，如无授权用 Archivo）
- **用于**：正文描述、导航链接、按钮文字、Kicker 标签
- **字号**：导航 `13px` / 正文 `16px` / 按钮 `14px`
- **字重**：正文 `300`，按钮 `600`，Kicker `700`
- Lausanne 是瑞士新现代主义字体，比 Helvetica 更温暖，比 Inter 更有历史质感，适合结合古典排版风格的现代产品

> **免费替代方案**：Google Fonts 上的 **Archivo** 或 **DM Sans**（非 Impeccable 禁用的常见默认，Archivo 有独特的字母形态，不落俗）

### 装饰点缀字体：Bodoni Moda（Google Fonts 免费）
- **用于**：大型装饰字母（Drop Cap 样式的初始字母）、页脚 Slogan
- **字号**：作为装饰时 `120px+`，作为 Slogan 时 `22px` Italic
- **字重**：400 Italic
- **颜色**：Gold 铂金 `#C8A84B`，opacity `0.15`（作为水印装饰时），`1.0`（作为 Slogan 时）
- Bodoni Moda 是 Bodoni 的数字原生版本，细笔画纤如发丝，对比度极大，单个字母就像雕塑

## 四、区域一：导航条

**尺寸**：高度 `72px`，固定顶部  
**背景**：毛玻璃①规格，见上方定义

**左侧 Logo：**
- 主文字 `Pixory`：Canela Light（或 Playfair Display Light），`22px`，Obsidian `#1C1917`
- Logo 旁边有一个 `6px` 的圆形装饰，**Gold 铂金 `#C8A84B` 实心填充**，带微弱 `box-shadow: 0 0 6px rgba(200,168,75,0.4)` 的淡金辉光，没有霓虹灯管感，是低调的奢华暗示

  - 动画 `280ms ease-out`
  - 这条金色下划线是整个页面「金框展柜」主题的呼应

**右侧按钮组（从左到右）：**

① 「下载 Android」次按钮：
- 样式：透明背景，`border: 1px solid rgba(28, 25, 23, 0.2)`，文字 Stone `#7A7670`，Lausanne 500，`13px`，圆角 `4px`，高 `40px`，宽 `120px`

② 「阅读文档」主按钮（**全场高优先级**）：
- **默认状态**：
  - 背景：Gold 铂金 `#C8A84B`（在整个浅色页面中，这是唯一一个金色背景的按钮，视觉上极为突出）
  - 文字：Obsidian `#1C1917`，Lausanne 700，`13px`
  - 尺寸：高 `42px`，宽 `148px`，圆角 `6px`（不用胶囊，用轻微方角，更符合「展柜」美学）
  - 常驻金色辉光：`box-shadow: 0 4px 16px rgba(200, 168, 75, 0.3), 0 1px 4px rgba(200, 168, 75, 0.2)`
  - 按钮内左侧有一个极小的书本图标，Obsidian 色，12px
  - 在浅色的毛玻璃导航条中，这个金色按钮会在第一眼被注意到
- **Hover 状态**：
  - 背景颜色变亮：`#D4B455`（加亮 10%）
  - 辉光增强：`box-shadow: 0 6px 24px rgba(200, 168, 75, 0.5), 0 2px 8px rgba(200, 168, 75, 0.3)`

- **Active**：`transform: translateY(0) scale(0.99)`，辉光恢复 default，有按下质感

## 五、区域二：英雄区

**高度**：`100vh`  
**布局**：左右双栏，左栏 `55%` 宽（文字内容），右栏 `45%` 宽（视觉构图）

**整体背景处理（这是本套设计最关键的视觉决定）：**
- 英雄区右上方占整个视口 **约 60% 面积**（网格第 7-12 列，全高）的区域，填充 Celadon 粉青玉 `#A8D8CF` 的纯色背景
- 这个粉青色块是整个页面中面积最大的颜色块，与左侧的 Chalk 白形成了「双版式」的强烈对比
- 粉青色块的左边界是一条垂直线，线的走向在移动端时变为水平线（响应式适应）
- 在粉青色块内部的右下角，有一个 Bodoni Moda Italic 的超大水印字母 `P`，字号约 `400px`，颜色 `rgba(28,25,23,0.04)`（极淡，几乎不可见，但近看会发现），增加页面的「珍宝馆标签」纵深感

**左侧文字内容区（白色背景）：**

Kicker 标签：
- 两个并排标签
- 第一个：背景 `rgba(200, 168, 75, 0.12)`，border `1px solid rgba(200,168,75,0.3)`，文字 Gold `#C8A84B`，内容 `本地原生 · BYOK`，Lausanne 700，`11px`，全大写，字距 `0.12em`，圆角 `4px`，内边距 `4px 10px`

- 行三：`Yours.`，颜色 Obsidian `#1C1917`，字号 `clamp(80px, 10vw, 140px)`（最大一行，压轴感）
- 行高 `1.0`，三行叠在一起形成一个强力文字块
- 行一和行三之间，有一条 `1px` 细横线（颜色 `rgba(28,25,23,0.1)`，宽度 `120px`，不对齐任何文字，只是中间的呼吸分段符）

- 内容：**「将本地 AI 记忆、无损资产归档、BYOK 密钥体系完整融合，你所有珍贵的故事与对话，都在物理设备上永久铸成，没有云端能够取走它们。」**

按钮组（纵向排列，贴近描述文字）：
- 主按钮「开启本地档案室 →」：
  - 背景 Obsidian `#1C1917`，文字 Chalk `#F7F4EE`，Lausanne 700，`15px`
  - 高 `52px`，宽 `240px`，圆角 `6px`

  - 颜色 Gold `#C8A84B`，Lausanne 600，`15px`
  - 左侧有一个卷轴/书本 SVG 图标，14px，同色
  - Hover：下划线从左侧展开（1px Gold 下划线，`transition: width 250ms ease`），文字颜色略微加深到 `#B89540`

**右侧视觉构图区（粉青色背景）：**

这个区域不放产品截图（避免失真），而是一个抽象的「珍宝馆展柜」构图：

  - 边框颜色从淡金变为 `rgba(200,168,75,0.6)` — 金边显现
  - 标签文字颜色变为 Obsidian `#1C1917`（从灰变深）

  - 过渡：`400ms cubic-bezier(0.19, 1, 0.22, 1)`

## 十二、全局动效规格

**页面加载序列（Timeline）：**
- `0ms`：背景色 Chalk `#F7F4EE` 立即显现（CSS 无需动画）
- `0ms`：英雄区右侧粉青色块，从 `opacity: 0, transform: scaleX(0)` 展开（`transform-origin: right`），`duration: 1000ms cubic-bezier(0.19, 1, 0.22, 1)`
- `200ms`：导航条 `translateY(-100%) → 0`，`duration: 600ms ease-out`
- `400ms`：Kicker 标签组 `opacity: 0 → 1, translateY(16px) → 0`，`duration: 700ms`
- `600ms`：主标题三行，每行从 `translateY(100%)` 入场（`overflow: hidden` 遮罩），逐行延迟 `150ms`，`duration: 1000ms cubic-bezier(0.16, 1, 0.3, 1)`
- `1000ms`：描述文字和按钮组 `opacity: 0 → 1, translateY(20px) → 0`，`duration: 800ms`
- `1100ms`：右侧档案格子九个标签，棋盘交替入场，`duration: 600ms`，`stagger: 60ms`

**滚动入场：**
- `IntersectionObserver`，`threshold: 0.1`，触发时 `opacity: 0, translateY(20px) → 1, 0`
- `duration: 700ms cubic-bezier(0.16, 1, 0.3, 1)`
- 数据横条的数字，使用计数器动画（`0 → 目标值`，`duration: 1000ms ease-out`）

**持续动效（常驻，无交互依赖）：**
- 导航条「阅读文档」Gold 按钮辉光脉冲：`animation: goldGlow 4s ease-in-out infinite`
  - `box-shadow` 从 `0 4px 16px rgba(200,168,75,0.3)` 到 `0 6px 28px rgba(200,168,75,0.5)` 再回来
  - 这是整个页面唯一一个持续动画的 UI 元素，确保任何时候都能吸引注意力

**鼠标追踪（仅桌面端）：**
- 英雄区右侧档案格子，整体跟随鼠标以极小的 `0.01x` 比例偏移（`perspective: 800px`，`rotateX` 和 `rotateY` 各不超过 `3deg`），制造精致的立体展柜感
