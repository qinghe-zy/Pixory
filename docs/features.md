# Pixory 完整功能白皮书

Pixory 致力于提供一个完全本地化、高度掌控的 AI 深度陪伴与视觉资产管理数字空间。以下为应用所包含的全量功能与交互细节清单：

## 一、AI 对话与基础交互
### 多模型接入与流式响应
   - 支持自由接入兼容标准 API 规范的前沿大语言模型（如 DeepSeek、OpenAI、Claude、Gemini 等）。
   - 具备高稳定性的流式生成引擎，不仅支持大段长文本的平滑渲染，还支持在应用退至后台时保持生成，随时中断与无缝恢复。
### 深度思考过程可视化与防抖绝对向下展开
   - **7 行双向淡出视口**：思考折叠态视口升级为 7 行规范（161dp 高度，23dp 行高），上下边缘均配备 24dp 渐变淡出遮罩（Top & Bottom Dual Fade），中央保证至少 5 行纯净可视区域，边缘过渡柔和自然。
   - **截断步长量化与高度防抖**：采用 300 字符步长量化截断与 ±4dp 行高微波动平抑，彻底根除流式思考生成时的容器高度微抖动。
   - **物理级绝对向下展开**：无论在生成中、生成完成、历史消息还是短对话底部边界，展开操作 100% 物理向下展开，标题按钮绝对 0 像素位移；单阶段原子展开锁与滚动上界净空破除视口上蹿与 Android 滚动限制，第一眼永远对准思考第一行。
   - **伴侣轻量化输出约定**：日常交流、Markdown 排版与代码示范自由输出无需包装 HTML 外壳，仅明确制作完整独立网页时才输出自包含单文件。
### 富文本消息渲染机制与 LaTeX 公式
   - **全面 Markdown 支持**：内置安全的 Markdown 解析器，支持复杂的代码块高亮与排版。
   - **专业 LaTeX 数学公式渲染**：内置高效公式解析引擎，完美支持独立多行数学公式与行内公式（如时间复杂度、微积分、矩阵等）的专业数学符号排版呈现，自动紧凑自适应。
   - **原生附件支持**：在聊天流中无缝以内联画廊的形式渲染原生图片附件。
   - **高级排版嵌入**：支持通过 WebView 渲染复杂的 HTML/CSS 块，支持富文本排版标签。
### 极速渲染、历史气泡免疫盾与长文折叠
   - **历史气泡绝对免疫盾**：流式生成期间切断历史气泡唤醒，实现 0 陪跑，杜绝长会话卡顿。
   - **纯文本极速 Fast-Path**：非流式且无 Markdown 触发符时单层原生 Text 直出，0 AST 解析，0 额外 View。
   - **历史超长长文与代码块智能折叠**：超长历史内容智能卡片折叠，展开或收起时长文阅读视口焦点绝对锁定（零像素跳动）；选择文本全屏弹窗富文本预览态默认免折叠。
### 精细化的气泡交互与操作
   - **用户消息操作**：支持对已发送消息进行复制、全屏选择文本、以及“原地修改并重新生成”。
   - **AI 消息操作**：支持复制、全屏选择文本、收藏、中断后继续生成、续答/单句回复、以及整体重新生成。
   - **智能菜单定位**：消息长按菜单精准判断手指所在的屏幕半区，自动在触点上方或下方 5px 处弹出。适配键盘弹起等界面状态，保持菜单稳定停靠。
   - **消息操作栏 1:1 复刻与金色收藏动画**：消息下方提供独立的快捷操作栏，收藏按钮支持一键直达，配合灵动的弹性点亮动画与金色填充。
### 聊天界面细节体验
   - **智能时间分割线**：聊天流会自动按照北京时间自然日插入日期分割线，并在当天或前一天显示“今天 / 昨天”，确保时间线清晰且不干扰对话文本。
   - **双侧抽屉导航**：支持全屏右滑呼出“综合记录抽屉”（历史会话），左滑呼出“会话设置抽屉”（模型与角色配置），快捷操作随滚动流利跟手。
   - **微距自然柔化淡出**：输入框与消息视口交界处配备 14px 微距自然淡出，滑动时文字柔化融入底色，消除生硬截断；输入框上边线刀削般分明锐利，底部配备实体防漏字保护。
   - **聊天列表长程飞滑**：减小基础滑动阻尼，智能感知快速强甩与连划意图切入低衰减高速巡航，长文翻阅极其省力。
### “AI 帮答”智能辅助
   - 输入框内置“AI 帮答”候选面板。提供阅读器式的候选界面，支持“短句 / 长句”模式切换，且在左右翻页与刷新时会完整保留候选历史。

## 二、长线记忆与时间线分支
### 平行分支与采用路线
   - 当对历史消息进行“编辑”或“重新生成”时，应用不会覆盖原对话，而是自动分支出一条平行的时间线路线。
   - **分支树界面**：提供完整可视化的分支路线图。针对超长会话，系统使用局部连线与可视区限制渲染。
   - **主线自动跟踪**：无论是“最近聊天”列表、聊天搜索还是后台预取，系统始终精确跟踪并显示你最终采用的“主线”结局，自动对齐上下文。
### 全局搜索与收藏
   - 支持在聊天流中对 AI 回复进行收藏，收藏内容会自动绑定当前的上下文分支。
   - 聊天全局搜索支持精准定位（Exact）与模糊搜索（Fuzzy），点击结果可瞬间穿梭回聊天的特定上下文位置。
### 认知级记忆演进闭环（Cognitive Evolution）
   - **显著性抽取门禁（Saliency Gate）**：伴侣敏锐区分“过场小事”与“核心事实”。洗澡、吃饭、拿外卖、等车等纯生理状态与即时寒暄不再被记入长期账本；真实偏好、身份事实、生活忌口即时放行，结合伴侣系统情感浓度（signalWeight >= 0.70）动态上浮重要性权重。
   - **ACT-R 检索负反馈与遗忘归档**：建立 `memory_claim_feedback` 账本，对连续 5 次注入大模型但 0 采纳的记忆计算 wastePenalty 衰减并转入 stale 归档，保持上下文极其精炼。
   - **刚聊内容去重惩罚**：在最近对话历史窗口中出现的记忆项赋予硬去重惩罚（redundancyPenalty 1.0），彻底杜绝“刚聊完一句伴侣转头就机械复读”的困扰。
   - **碎片自动聚类升维**：后台维护任务自动将同主题零散经历（>= 3条）聚合提炼为深层的稳定画像（Confirmed），陪伴更加默契懂你。

## 三、深度陪伴与运行时系统
### 角色定义与独立设定
   - 每个会话均可绑定独立的“角色卡”，自定义角色的核心指令、性格、问候语，并支持给角色分配专属头像及标签（如默认开启“我的头像”显示，亦可针对单个会话关闭）。
### 角色日记（自动回溯）
   - 系统会在后台定期梳理你们的聊天日常。当积累足够互动后，AI 会自动以角色的口吻和视角，生成带有情感温度的“专属日记”。
### 离线思绪与内心独白
   - **情感事件触发**：本地规则引擎会在对话中敏锐捕捉诸如“脆弱、受伤、和解、道歉、赞美、冷淡”等情感事件。
   - **独立思绪生成**：在触发事件后的 10 分钟会话窗口内，系统会在后台悄悄批量生成角色的“内心思绪”（每个角色每天最多 3 条），这些念头属于 AI 的私密想法，不会直接出现在聊天页。
   - **内心产物仲裁**：用户可进入“内心独白”面板查阅并管理这些思绪与梦境，长按可进行多选永久删除。只有用户显式许可的内容才会被纳入未来的对话上下文。
### 离线梦境生成
   - AI 会基于长期的相处记忆，在空闲时自主发散生成角色风格的“梦境片段”，丰富陪伴的立体感。

## 四、知识挂载与本地 RAG (检索增强生成)
### 多格式文档生命周期管理
   - 支持向本地导入纯文本、TXT、Markdown、PDF、DOCX 等多种格式文件。
   - 系统会自动进行分块（Chunking）、生成向量（Embedding），支持单文档阅读以及跨会话、跨 IP 的归属挂载。
### 防幻觉与精确引用（Citation）
   - 采用多路混合检索（Hybrid Retrieval）向大模型输送背景资料。
   - **严格验证**：大模型生成的所有文献引用标记，应用底层都会进行“来源可见性、文件哈希校验、以及词面支撑验证”。提供严格的引用溯源标记，支持在聊天流中快速查阅原始出处。
### 沙箱两步确定性数据查询与短设定固化
   - **沙箱两步 SQL 查询**：未配置向量模型时，针对 CSV/Excel 等表格文档（≤5MB），系统会自动将其解析为本地 SQLite 临时表，通过只读 `SELECT` 安全检索，两步精确获取结构化数据，8 秒超时安全退避为语义切片。
   - **短设定原文稳定区固化**：在聊天中发送的重要短篇设定（≤2500字）或临时资料，支持通过气泡一键“存入资料库”，直接固化注入提示词稳定区享受大模型 Prefix Cache 极速响应；5 秒全系统统一毛玻璃 Toast 可逆撤销；临时会话附件单轮脱水不污染记忆库。

## 五、AI 交互式沙箱系统与创意制品
### 轻量按需交互架构
   - “伴侣为本，沙箱为器”：支持 2D 小游戏、WebGL/Three.js 动效、物理模拟、动态交互图表与独立单文件网页。
### Claude 方案 A 沙箱小卡片 1:1 精密复刻
   - **纯白亮底与发丝细线**：纯白底色 `#FFFFFF`、细微边框 `#E2E8F0`、32dp 温润浅灰幽灵胶囊按钮，彻底剔除粗黑脏阴影（`elevation: 0`）。
   - **绝对杜绝变形错位**：收拢与展开态操作按钮双向 32dp 物理尺寸绝对锁死；独立 Key 隔离（`key="sandbox-collapsed-card"` vs `key="sandbox-expanded-viewfinder"`）杜绝 Android ViewTag 错位复用导致按钮变大错位。
### 最新消息白底取景框与 HUD 线框舞台
   - **流式首行嗅探即时占位**：代码块刚开口前 60 字符嗅探命中 `<!DOCTYPE html>` 或 `<svg` 根节点后，原地浮现白底极光取景框（Mini-Stage 0.42x 相机等比视口映射），0 源码刷屏，0 额外显存占用。
   - **拟真线框舞台**：内嵌拟真线框舞台（HUD 状态指示、发丝三线网格、中央白玻立体中枢、动态 `<title>` 实时上屏与实时代码行数跳动），代码生成好后即刻揭开运行画面。
### 全会话单例调度与原地方框形变
   - **单例互斥调度**：全局引入单例协调器，展开任一卡片或新流式到达时自动广播，其他取景框以 260ms 缓出收拢为小卡片，确保全会话物理级至多 1 个活跃 WebView，极速省电并杜绝低端机显存溢出。
   - **原地方框变速形变**：点击卡片右侧方框按钮，即可伴随高级变速动力学（320ms 弹性展开、260ms 缓出收拢）在原地平滑展开为完整取景器或收拢复原，过渡半程全程点亮全息极光扫弦。
   - **全屏沉浸畅玩**：点击胶囊运行按钮直出全屏沙箱，支持横屏旋转、微调代码，身临其境畅玩小游戏与交互制品。
### 全域沙箱入口与纯净独立离线 HTML 导出
   - **全域沙箱入口覆盖**：原生富文本 HTML 右上角极简运行、气泡长按菜单沙箱运行、“选择文本”全屏弹窗左上角 [预览 / 源码] 双模无缝切换、超长代码块头部一键运行。
   - **纯净独立可执行导出**：导出的 HTML 文件为 100% 独立纯净的应用程序源码，杜绝字符实体转义、多余排版外壳与商业水印，自动补齐标准 UTF-8 声明，电脑与手机浏览器双击离线即玩。

## 六、视觉资产：导入与查重
### 极速与无损海量导入
   - 支持跨平台图片、视频混合选取导入。单次操作支持高达 1000 个文件或 32GB 总体积，底层采用最高 4 线程并发进行原文件物理拷贝，保留原版画质与编码格式。
   - 支持 Android 11+ 的系统级删除确认（导入后清理原相册），保证数据不丢失。
### 极严苛的双重查重拦截
   - **精确哈希查重**：在文件级计算 SHA-256，通过 SQLite 分组语句极速过滤出内容完全一致的文件。
   - **视觉感知查重**：提取图片的视觉特征（Visual Hash），即使分辨率不同、经过了轻度裁剪的图片也能被揪出。
   - 查重拦截在文件实际写入磁盘前（Preflight）执行，降低冗余存储占用。

## 七、视觉资产：浏览与沉浸体验
### 超清图片阅读器
   - 底层采用 81 项大容量锚点窗口与自适应解码预取机制，保障大图快速滑动时的流畅渲染。
   - 包含 Personal 私密内存会话缓存，精确记忆每次浏览退出的位置。并微调了长按响应延迟，提供优化的滚动与长按手势体验。
### 沉浸式短视频体验
   - **纵向手势操控**：提供纯净的纵滑视频浏览。内部维持“当前+前向3个+反向1个”的视频预加载池，切换时瞬间响应无黑屏，且只有当前可见的视频才会激活音轨。
   - **保音高调速**：支持从 0.5× 慢放至 3.0× 极速播放。底层引擎会自动锁定音调（Pitch Preservation），维持自然的听觉体验。

## 八、视觉资产：整理与全局检索
### 三级结构化收纳
   - 采用“全局 IP - 分组 - 标签”三层逻辑。标签体系采用双列流式布局，系统会根据使用频率和最近使用时间自动排序“热门/近期标签”。
### 高效的批量管理工作流
   - 提供专属的“批量管理”面板，在有明确游标范围的虚拟化列表中，支持精准多选、批量更改所属分组、批量追加或移除标签。
### 全局检索与历史树
   - **极致搜索**：所有筛选操作（按 IP、分组、标签）均直接在底层 SQLite 执行限制返回，约 250ms 防抖响应，实现高效数据过滤。
   - **树状历史**：全局搜索历史面板支持按“年 / 月 / 日”三级树状结构折叠与统计，且点击任意层级可无缝路由回对应的数据流。
### 带溯源的回收站
   - 执行删除操作时仅进行数据库标记（软删除），数据平移至回收站。支持单体或全量还原，以及到期后物理空间的彻底清理。

## 九、双重空间与极致隐私
### 物理隔离的双空间系统
   - 应用分为“普通空间 (Normal)”与“私人空间 (Personal)”。两者不仅是在界面上隐藏，而是拥有**两套完全隔离的 SQLite 数据库、两套独立的文件存储目录**。
### 严苛的权限与锁机制
   - **凭证分离**：支持设置独立的九宫格图案锁，并完全兼容系统级的指纹/面容解锁。
   - **防暴力破解**：多次输入错误将触发系统级的时间惩罚锁定。
   - **自定义恢复密钥**：提供轻量的 `XXX-XXX` 格式自定义安全恢复密钥。
### 瞬态销毁与阻断保护
   - 解锁时仅激活当前所需的根分页。
   - **落锁阻断**：私人空间一旦锁定，应用会瞬间且彻底地销毁内存图片缓存、阅读器会话状态、聊天预取队列，并中止且失效所有相关的 AI 生成、备份与维护等后台任务。

## 十、数据主权与存储掌控
### Manifest V2 全量无损备份
   - **打包导出**：可将整个应用的数据库、原图、视频、独立缩略图、AI 聊天附件、甚至是自定义的角色头像，通过单次最多 4 并发工作流打包为一个完整的备份压缩包。
   - **无损恢复**：恢复过程包含对文件相对路径、大小以及 SHA-256 的强校验。采用原子化事务合并，支持原子化事务恢复，保障数据库一致性。
   - 密钥（如连接大模型的 API Key）只保存在操作系统的安全区域（SecureStore），不随备份文件导出。
### 多维度存储用量透视
   - 提供直观的存储分析面板，采用“生命周期快照（epoch+TTL）”算法，瞬间计算出设备上原图、缩略图、系统缓存、备份文件与回收站分别占用的字节数。
   - 提供一键深度清理冗余空间入口。
### Token 消耗透明化
   - 应用内具备详尽的 AI 用量分析面板，可按会话或按总览查看请求量。
   - **缓存观测**：独家支持原生 Provider（如 DeepSeek）的 `prompt_cache_hit_tokens` 拦截，明确展示用户的提示词缓存命中量与未命中量，提供透明的调用成本追踪。
### 外部内容捕获（分享扩展）
   - 深度集成 Android 的系统级 Share / Open-With 接口，在其他 App（如相册、文件管理器）中可直接将图片、视频和备份压缩包分享投递至 Pixory 中。
