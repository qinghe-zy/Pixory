# Pixory 完整功能白皮书

Pixory 致力于提供一个完全本地化、高度掌控的 AI 深度陪伴与视觉资产管理数字空间。以下为应用所包含的全量功能与核心特性清单：

## 一、AI 对话与基础交互
### 多模型接入与稳定流式体验
- 自由接入兼容标准 API 的前沿大语言模型（如 DeepSeek、OpenAI、Claude、Gemini 等）。
- 具备高稳定性的流式生成引擎，支持切至后台保持生成、随时中断与无缝恢复。
### 思考过程与富文本排版
- **推理过程呈现**：支持具备推理能力的大模型展示思考过程，折叠与展开平滑自然。
- **专业排版与数学公式**：全面支持 Markdown 代码高亮、LaTeX 数学公式（行内与多行矩阵自适应排版）以及内联画廊图片展示。
### 流畅的长会话与气泡操作
- 超长文本智能折叠与长列表流畅滑动，保障长对话稳定不卡顿。
- 支持消息复制、全屏选词、单条编辑重发、收藏与便捷操作菜单。
### 推挤缩放式侧边栏与交互体验
- 支持推挤缩放式（Push & Scale）与经典抽屉双模式切换，随滚动跟手自如，快速切换会话与配置。
- 独立聊天视觉排版定制，支持多种配色主题、气泡圆角与字号微调。
- 内置"AI 帮答"候选面板，支持短句与长句智能输入辅助。
### 系统管家协助
- 内置独立「系统管家」AI 助手，负责无障碍地协助完成应用内操作（如角色创建、设置导航、空间切换等），与普通 AI 会话在数据与权限上完全隔离，零记忆越权。
- 操作进度以可视化事件流逐步展开，关键步骤提供动态确认卡，支持查看详情、撤销与重试，操作结果清晰可审计。
- 全局功能搜索卡涵盖设置、导航、历史等全量入口，系统管家与全局搜索共享统一注册表，新增入口自动联动。

## 二、长线记忆与时间线分支
### 平行分支与路线回溯
- 对历史消息编辑或重新生成时，自动生成平行分支路线，旧版本完整保留。
- 提供可视化分支树，主线进度自动对齐，适合角色扮演、故事推演与灵感探索。
### 认知级记忆演进闭环
- **智能偏好捕捉**：自动识别日常对话中的喜好偏好、身份事实与重要经历，过滤即时闲聊寒暄。
- **记忆动态迭代**：长期未引用的冗余信息自动降权，避免机械复读；同类碎片记忆聚合沉淀为深层画像，让角色越聊越懂你。
### 全局检索与收藏穿梭
- 支持对关键回复一键收藏，与当前分支自动绑定。
- 支持全文精准与模糊搜索，快速穿梭回特定对话时空。

## 三、深度陪伴与运行时系统
### 人设定义与角色卡
- 自由创建和管理角色卡，自定义性格、世界观背景、专属问候语与独立头像。
### 角色日常回溯（专属日记）
- 后台梳理日常深度对话互动，以角色口吻生成带有情感温度的专属日记。
### 离线思绪与内心独白
- 本地捕捉对话情绪起伏，在幕后自主生成私密独白，用户可查阅并自主决定是否纳入后续对话。
### 离线梦境生成
- 基于相处经历在空闲时发散生成角色风格的梦境片段，丰富陪伴的立体感。

## 四、知识挂载与本地 RAG 检索
### 多格式文档知识库
- 支持导入 Markdown、PDF、DOCX、TXT 等多种格式，本地自动切片与向量化管理。
- 可按主题（IP）或会话灵活挂载，充当大模型的背景世界观与资料库。
### 防幻觉与精确引用溯源
- 多路混合检索增强生成，回复内容附带严格的文献引用标记，随时回溯原文出处。
### 结构化查询与设定固化
- 支持对表格数据进行本地精确结构化查询。
- 聊天中的关键短设定可一键固化存入资料库，注入提示词稳定区享受缓存加速。

## 五、AI 交互沙箱与创意制品
### 轻量交互与即时运行
- 支持在对话中直接运行 2D 小游戏、WebGL/Three.js 交互动效、物理模拟、图表及独立网页。
- 代码流式生成时以极简取景器占位，生成完毕即刻呈现交互画面，告别大段代码刷屏。
### 沉浸全屏与单例调度
- 支持一键进入全屏沉浸畅玩，支持横竖屏自适应与代码实时微调。
- 全局单例调度机制，确保运行流畅省电、低内存占用。
### 多格式导出中心
- **制品导出**：沙箱制品支持导出为 100% 纯净独立的单文件 HTML，无水印、无外壳，电脑或手机浏览器双击即可离线运行。
- **消息多格式导出**：聊天内容支持导出为 Markdown、纯文本 TXT、完整 HTML、标准化 JSON 及 PDF 五种格式，智能识别普通文档与可执行制品，分别以对应格式完整导出。
- **多路分发**：支持一键复制到剪贴板、系统原生文件分享，以及通过 SAF 接口保存到系统目录，与第三方应用无缝互通。

## 六、视觉资产：导入与查重
### 极速与无损海量导入
- 支持跨平台图片、视频混合批量导入，原文件物理拷贝，完整保留原始画质与 EXIF 信息。
- 多线程并行安全复制，缓解大批次导入耗时；导入前执行容量预检，保护设备存储安全。
- 支持系统级删除确认（导入后清理原相册），保护素材安全。
### 双重智能查重拦截
- **精确哈希查重**：文件级哈希极速比对，过滤完全一致的文件。
- **感知视觉查重**：提取视觉特征，精准揪出分辨率不同或轻度裁剪的重复图片。

## 七、视觉资产：浏览与沉浸体验
### 超清图片阅读器
- 高性能大图滑动与缩放，平滑流畅，自动记忆退出浏览位置。
### 沉浸式短视频体验
- 顺畅的手势滑动浏览，视频快速预载秒开，支持 0.5×~3.0× 保音高变速播放。

## 八、视觉资产：整理与全局检索
### 三级结构化收纳
- "全局 IP - 分组 - 标签"三层层级，标签根据使用习惯智能推荐。
### 批量管理与全局检索
- 支持多选批量更改分组与标签；支持按 IP、标签多维筛选，支持按时间树折叠查看。
- 批量整理操作具备事务级撤销能力，防止误操作造成素材归属混乱。
### 安全回收站
- 采用安全软删除机制，误删可一键还原，彻底清理需用户二次确认。

## 九、双重空间与极致隐私
### 物理隔离的双空间系统
- 拥有"普通空间"与"私人空间"，两者拥有完全独立的 SQLite 数据库与物理存储目录。
### 严苛的门禁保护
- 支持图案锁、指纹/面容解锁以及自定义安全恢复密钥。
### 落锁即时清理
- 私人空间锁定后，瞬间释放内存图片缓存与任务上下文，确保私密数据安全。

## 十、数据主权与存储掌控
### 全量无损备份与恢复
- 支持一键完整打包数据库、原图、视频、附件及角色资产，支持跨设备无损还原。
- API 密钥仅保存在系统硬件安全区（SecureStore），不随备份文件导出。
### 存储透视与清理
- 多维度存储快照统计原图、缩略图、缓存、备份与回收站的实际占用，支持一键释放冗余空间。
- 普通空间与私人空间分别独立统计，保障隐私边界清晰可见。
### 用量与缓存透明化
- 详尽统计模型请求量与 Token 消耗，支持提示词缓存（Prompt Cache）命中分析，帮助用户合理评估 AI 调用成本。
### 系统级外部内容捕获
- 深度集成系统级分享接口，随时从相册或其他应用直接投递素材至 Pixory。

## 十一、交互动效与性能稳态
### 精致视觉反馈体系
- 边缘极光入场动效为重点界面带来沉浸过渡感，AI 档案页提供星轨行星环绕视觉反馈。
- 聊天生成期间声纹频谱动效实时呈现 AI 思考节奏，增强陪伴临场感。
### 低端机自适应性能门禁
- 动效组件在页面不可见或应用进入后台时自动停止循环，释放 CPU 与内存资源。
- 列表热路径关闭重型渲染组件，确保在低端 Android 设备上滚动帧率稳定。
### 冷启动与响应速度优化
- 数据库与目录并行初始化，原生 Splash 等关键字体加载完成后才隐藏，杜绝白屏闪烁。
- 聊天入口利用路由切换间隙预取首屏消息，进入会话即时可读，无需等待加载。
