Release Notes

稳定。清晰。耐用。更新不是喧哗，是秩序继续变清楚。

2026-06-24

Version 2.5.1

连续性导入

支持把 Pixory 原生续聊包直接接回，也支持把其他平台整理出的迁移文档导回当前线程，继续沿着角色与分支上下文聊天。

记忆审读门禁

外部导入内容先做结构提取，再交给记忆模型审读和验收；可解析消息会渲染到聊天页，其余压缩内容也会走审读后再进入后续记忆链路。

附件可回放

聊天附件改为持久化保存，重试、再生成和后续回放都能重新附带原始图片或文档上下文，不再丢失附件语义。

模型与播放器修复

Provider 模型支持删除手动/同步模型并自动清理默认值与会话悬挂引用，同时修复视频播放器随机逻辑和相关记忆维护缺口。

2026-06-13

Version 2.4.5

AI 工作台更顺手

工作台加入最近角色头像、最近聊天和紧凑入口，最近聊天显示完整日期时间，并按页面级节奏拉开组件间距。

历史记录更干净

空白新聊天不再进入历史和最近列表，普通/私密空间切换时不会短暂显示上一空间会话。

服务器主下载

应用内更新默认跳转官网获取区，下载区默认使用 mist01.com 服务器直下最新版 APK，GitHub Release 保留备用和历史版本。

2026-06-09

Version 2.4.4

长会话渲染更轻

AI 聊天把可见消息派生、头像分组和反转列表索引集中在一次计算里完成，减少长对话中重复的全量扫描和定位开销。

发布前回归修复

补做一轮代码 review，修复分支回看、搜索定位和内联编辑相关的风险点，同时保留首字等待收敛和版本按需加载优化。

2026-06-09

Version 2.4.3

首字等待收敛

AI 聊天资料检索改成关键词优先，只有在直接结果不足且资料确实存在 embeddings 时，才继续触发 query embedding，减少首字前空跑等待。

旧版本回看更稳

聊天消息默认不再加载所有历史版本，旧版本改成按需加载；同时修复分支树切换、旧版本回看和消息刷新时偶发显示错误版本的问题。

2026-06-01

Version 2.4.2

聊天搜索 & 收藏

AI 聊天页新增整页搜索，精确结果优先，本地模糊结果随后展示。回复可以加入收藏中心，显示来源聊天，并支持回到原消息位置。

分支记忆与定位优化

优化聊天进入、搜索返回和收藏跳转时的路线恢复，减少回到错误分支。长对话加载更早消息时保留当前路线，提高目标消息定位稳定性。

2026-05-30

Version 2.4.1

聊天历史回收站新增移出回收站入口，支持单条和批量恢复，永久删除继续独立保留。

2026-05-29

Version 2.4.0

新增 AI 创作路线树，支持关键分支查看、多分支折叠、主路线持久化和路线数据导入导出保护。

2026-05-26

Version 2.3.9

进一步修复 AI 聊天 Markdown Android 遮挡问题，并加入 EAS Update 热更新底包能力。优化 AI 角色详情海报式展示。
