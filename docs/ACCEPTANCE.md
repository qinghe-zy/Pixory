# Pixory MVP 验收标准

更新时间：2026-05-02

## MVP 验收标准

- 可在 Android 端离线创建 IP
- 可在同一 IP 下创建分组
- 可批量导入图片到指定 IP / 分组
- 导入后能在首页、IP 详情、分组页、全部图片页看到真实数据
- 图片详情页能展示原图、标签、备注、收藏、尺寸、大小、格式
- 标签总览页与标签结果页可基于真实 SQLite 数据工作
- 收藏页可基于真实 SQLite 数据工作
- 最近查看页可基于 `lastViewedAt` 工作
- 删除默认走软删除
- 回收站支持恢复
- 回收站支持清空
- 清空回收站时先删除数据库记录，再删除原图与缩略图文件，并展示部分文件失败项
- 清空回收站后必须独立核验 SQLite 记录删除、原图删除、缩略图删除、未删除图片文件仍存在
- 不引入服务器、云存储、账号系统

## 已验证功能清单

- 首页四 Tab 已上线：首页、分组、标签、我的
- 标签页、标签结果页、收藏页、最近查看页、回收站页已接真实 SQLite
- 图片导入主链路可在 Android 模拟器中真实执行
- 图片详情页原图可预览
- 导入后 GroupA 展示 4 张图片
- 导入后图片详情中的 `tagA / tagB / release regression note / 已收藏` 显示正确
- GroupA 页缩略图可展示
- 回收站恢复与清空功能代码已到位，历史回归已走通

## Android 回归结果

本轮 fresh bundle 回归使用：

- 命令：`pnpm exec expo start --android -c`
- 设备：`sdk_gphone64_x86_64`
- Android：15

结果结论：

- 导入链路通过
- 首页 / GroupA / 图片详情的核心显示通过
- “编辑图片时精确写入指定字符串并完成整条后续链路”未完全闭环

阻塞原因不是已确认的 Pixory 业务 bug，而是 Android 模拟器输入法与自动化文本注入干扰，导致编辑阶段的精确字段值不稳定。

## 仍需后续验证的项目

- 最终 Android 长链路完整闭环人工复核
- 编辑 1 张图片后，确认 GroupA 减 1、GroupB 加 1 的完整 UI 证据
- 批量管理剩余图片后的最近查看 / 标签 / 收藏联动复核
- 回收站清空后的外部独立物理删除核验：数据库记录不存在、原图不存在、缩略图不存在、其他图片仍存在
- 截图整理与提测材料归档

## 最近查看规则

- 打开图片 Viewer 算查看
- 在 Viewer 中滑动到另一张图片算查看
- 打开图片详情页算查看
- 仅在缩略图列表中曝光不算查看

## 搜索验收

- 首页搜索框进入全局搜索页
- 全局搜索覆盖 IP、分组、标签、文件名、备注
- 首页不再承诺一个只筛 IP 的“标签搜索”

## 不在 MVP 范围内

- 搜索增强
- 高级筛选
- 云服务
- 登录 / 账号体系
- AI 标签
- AI 生图
- Web 后台
- 路由大重构
- UI 大改版
