# Pixory v2 Video and Import Spec

本文档定义 v2 视频、导入、临时查看和跨空间迁移的可实现规格。计划文档负责方向，本 spec 负责开发时必须遵守的具体规则。

## Visual Reference

播放器视觉参考图：

![Pixory v2 video player visual reference](./assets/v2-video-player-visual-reference.png)

说明：

- 该图用于确认播放器的整体信息密度、沉浸层级、底部一排控制、轻量返回按钮和待播放向上展开方向。
- 实现时以本 spec 的交互和数据安全规则为准，不要求逐像素复刻生成图。
- 生成图不得包含系统状态栏；实际产品页面也不得把系统状态栏做进页面图片资产。

## 范围

包含：

- 图片导入页收口。
- 视频导入、封面、详情、查看。
- 外部视频临时查看。
- 压缩包图片临时阅读。
- 大任务进度。
- IP 普通空间 / 隐私空间迁移。
- 与备份、回收站、搜索、标签、分组的基础衔接。

不包含：

- 视频编辑、压缩、转码、裁剪。
- 视频批量管理。
- 视频方图、横图、竖图筛选。
- 云同步、账号、远程播放。
- 将外部 URI 或临时缓存直接登记为正式原文件。

## 数据模型

资产记录需要支持图片和视频：

```txt
mediaType: image | video
originalFileUri
thumbnailFileUri
coverThumbnailFileUri
originalFilename
internalFilename
width
height
durationMs
mimeType
fileSize
ipId
groupIds
tagIds
note
isFavorite
deletedAt
createdAt
updatedAt
lastViewedAt
lastPlaybackPositionMs
```

实现原则：

- 允许沿用现有 `image_assets` 命名，但必须用 `mediaType` 区分图片和视频。
- 图片的 `durationMs` 为空。
- 视频的 `thumbnailFileUri` 可以指向视频封面；如果实现拆出 `coverThumbnailFileUri`，必须保持列表和备份兼容。
- SQLite 不保存大文件二进制。
- 所有列表查询必须能按 `mediaType` 过滤。

## 导入页

入口必须语义明确：

- `选择图片`：只能选择图片。
- `选择视频`：只能选择视频。
- `选择资源包`：只能选择 `.zip` / `.pixorypack`。
- 如果支持混选，入口必须叫 `选择素材`，不能叫 `选择图片`。

导入页文案规则：

- 删除实现细节型文案，例如“复制原图，缩略图单独生成”。
- 删除流程解释型文案，例如“会先解压到 Pixory 私有临时目录”。
- `选择资源包` 只保留必要格式提示：`支持 .zip / .pixorypack`。
- 新增入口只写用户决策需要的信息，不写内部处理流程。
- `当前 IP` 和 IP 名同行展示。
- IP 名必须使用特殊视觉标识，例如胶囊、标签、徽标或轻量描边。
- `当前 IP` 下方不再显示重复说明。
- 分组选项内部可保留短说明，例如 `暂不分组 / 导入到当前 IP`。

## 视频导入

视频导入流程：

```txt
选择视频
-> 检查文件可访问性和剩余空间
-> 复制原视频到 temp/importing
-> 校验复制后大小
-> 移动或复制到 originals
-> 读取 width / height / duration / mimeType / fileSize
-> 生成单张视频封面
-> 写入 SQLite
-> 写入标签、分组、import batch 关系
-> 显示导入结果
```

要求：

- 原视频不压缩、不转码、不裁剪、不重编码。
- 视频复制不能进入 JS 内存，不能 base64。
- 封面生成失败不能导致原视频导入整体失败；视频记录应进入可重试封面状态。
- 大视频导入必须显示任务进度。
- 失败要保留原因、源文件名和重试入口。

## 大任务进度

适用任务：

- 视频导入。
- 图片批量导入。
- 资源包导入。
- 压缩包导入。
- 备份和恢复。
- IP 跨空间迁移。
- 批量清理。

任务状态至少包含：

```txt
pending
preparing
copying
verifying
generatingPreview
writingDatabase
completed
failed
cancelled
```

展示要求：

- 能拿到字节进度时显示百分比。
- 不能拿到字节进度时显示真实阶段和已处理数量。
- 必须显示当前阶段、总数、已成功、失败数。
- 不使用假百分比。
- 离开页面后任务状态不能丢失。
- 大任务不能阻塞浏览、搜索、查看已有资产。

## 视频播放器

播放器入口：

- 正式视频资产从视频详情页或资产列表进入。
- 外部视频从系统文件管理器或分享入口进入临时查看器。
- 列表页、搜索页、标签页、分组页不得挂载播放器实例。

播放内核要求：

- 使用成熟原生播放器能力。
- 视频源走本地 URI 或系统授权 URI。
- JS 不读取完整视频，不保存视频二进制，不 base64。
- 同一时间只允许一个活跃播放器实例。
- 离开页面、切后台、切换视频时必须 pause / unload。

控制层要求：

- 支持竖屏播放和横屏播放。
- 横竖屏切换不丢当前播放进度。
- 控制层 3 秒无操作后自动隐藏。
- 沉浸状态只显示视频内容。
- 点击视频区域后显示控制层。
- 返回按钮为轻量图标按钮，不加边框，不做大卡片。
- 底部只允许一排控制按钮。
- 底部控制区包含播放/暂停、进度、时间、倍速、横竖屏、待播放入口。

倍速要求：

- v2 必须支持：`0.25x`、`0.5x`、`0.75x`、`1x`、`2x`、`3x`。
- `8x`、`16x` 是高级可选能力，只有真实设备验证稳定后展示。
- 3x 必须真实设备验证稳定。
- 高倍速不稳定时不展示，或降级为连续 seek 快进。

拖拽要求：

- 用户可以左右滑动视频区域拖拽进度，不要求点到进度条。
- 手势 UI 必须跟手。
- seek 请求必须节流，不能每个手势事件都 seek。
- 拖拽时显示当前时间。
- 当前帧预览优先使用原生能力；不稳定时可低频 seek 或预生成关键帧降级。
- 松手后执行准确 seek。

长按快进要求：

- 支持长按快进。
- 长按快进倍数可设置。
- 长按快进必须优先保证不卡死。

待播放要求：

- 右下角提供待播放按钮。
- 待播放默认不展开。
- 待播放按钮与底部进度/控制区齐平。
- 点击后从右下角向上展开。
- 展开层不能挤压底部控制栏。
- 待播放列表显示当前 IP 下其他视频。
- 支持一键切换视频。
- 切换视频后保留当前 IP 上下文。
- 3 秒无操作后待播放浮层随控制层隐藏。

## 外部视频临时查看

外部视频临时查看用于从系统文件管理器或分享入口打开非 Pixory 正式资产。

规则：

- 不写正式资产记录。
- 不进入 IP、分组、标签、收藏、最近查看、回收站、备份。
- 播放源使用系统授权 URI。
- 不把外部 URI 登记为正式原视频。
- 长按视频提供 `保存到某个 IP`。
- 保存目标只显示普通模式 IP，不显示隐私空间 IP。

保存路径：

```txt
保存到已有 IP
-> 打开普通模式 IP 选择界面
-> 选择 IP
-> 走正式视频导入流程
-> 返回外部视频查看位置
-> 显示保存完成
```

```txt
保存到新建 IP
-> 打开新建 IP 界面
-> 创建普通模式 IP
-> 走正式视频导入流程
-> 返回外部视频查看位置
-> 显示保存完成
```

不得：

- 保存后跳首页。
- 保存后跳 IP 详情。
- 引导用户进入应用主流程。
- 写入隐私空间。

## 压缩包临时阅读

压缩包临时阅读用于打开图片压缩包，不等同于导入资产库。

支持：

- `.zip`。
- `.cbz` 可作为 zip 兼容格式处理。
- `.pixorypack` 只有在符合 Pixory 包结构时进入资源包导入，不当成普通临时阅读包。

流程：

```txt
打开压缩包
-> 建立临时 session
-> 扫描条目
-> 过滤图片候选
-> 按需解压当前图片和前后少量图片
-> 阅读
-> 退出后清理 session temp
```

规则：

- 不写正式资产记录。
- 不进入 IP、分组、标签、收藏、最近查看、回收站、备份。
- 不一次性全解压。
- 不把整包图片读入内存。
- 预加载窗口必须有限制。
- 临时缓存大小必须有限制。
- 异常退出后下次启动按 TTL 清理残留。

长按图片：

- `保存到相册`：将当前临时图片保存到系统相册。
- `保存到某个 IP`：走正式图片导入逻辑。

保存到 IP 要求：

- 复制到 originals。
- 生成缩略图。
- 写 SQLite。
- 校验文件。
- 保存后不强制切换主页面。
- 只显示保存完成。
- 用户下次进入应用时可继续处理分组、标签、备注。
- 临时缓存文件不能直接登记为正式 original。

安全要求：

- 防 zip slip。
- 防假扩展名。
- 防超大文件。
- 防超多条目。
- 防解压炸弹。
- 以 MIME 或魔数识别为准，不只信扩展名。

## IP 跨空间迁移

入口：

- 首页 IP 长按弹窗加入 `移入隐私空间` / `移出隐私空间`。
- 普通空间 IP 显示 `移入隐私空间`。
- 隐私空间 IP 显示 `移出隐私空间`。

认证：

- 移入隐私空间前必须验证隐私密码。
- 未设置隐私密码时先引导设置。
- 不要求每次移入都修改密码。
- 移出隐私空间必须在隐私空间已解锁状态下执行。

迁移性质：

- 普通空间和隐私空间是两套 SQLite 数据库和两套文件目录。
- 迁移不能只改字段，必须复制数据和文件。
- 迁移必须作为可见任务执行。

迁移内容：

- IP 记录。
- 分组。
- 图片和视频资产记录。
- 标签关系。
- 封面关系。
- import batch 和 import batch items。
- originals 文件。
- thumbnails / video covers 文件。

ID 映射：

```txt
normalIpId -> personalIpId
normalGroupId -> personalGroupId
normalImageId -> personalImageId
tagName -> targetTagId
```

标签规则：

- 标签按规范化名称复用。
- 目标空间已有同名标签时复用目标空间 tagId。
- 目标空间没有同名标签时创建新标签。
- 不把源空间 tagId 写入目标空间。

分组规则：

- 分组属于 IP 内部结构。
- 分组随 IP 复制。
- 分组不按全局名称合并。

安全顺序：

```txt
读取源空间
-> 复制文件到目标空间 temp
-> 写目标数据库
-> 校验目标记录和文件
-> 切换目标文件到正式目录
-> 再处理源空间
```

要求：

- 完成前不能删除源空间数据。
- 失败时优先保护源空间原始文件和源数据库记录。
- 严禁出现两边都不可用。
- 迁移结果必须显示成功、失败、跳过、校验结果。

## 备份和恢复

- manifest 必须区分 `image` / `video`。
- 视频备份必须包含原视频。
- 图片备份必须包含原图。
- 视频封面和缩略图可备份，也可标记为可重建。
- 恢复时先校验 manifest，再恢复数据库和文件。
- 几百 GB 场景优先考虑文件夹备份或分卷，不强依赖单个巨大 zip。

## 搜索和列表

- 资产列表必须支持 `mediaType` 过滤。
- 视频不进入图片专属批量管理。
- 视频不参与方图、横图、竖图、全景图筛选。
- 搜索结果可包含视频，但视频条目必须显示视频标识和时长。
- 标签结果和分组结果可显示视频，但视频不显示图片专属操作。

## 错误状态

必须明确处理：

- 文件不可访问。
- 外部 URI 权限失效。
- 剩余空间不足。
- 复制失败。
- 文件大小校验失败。
- 封面生成失败。
- 播放器不支持编码。
- 视频播放失败。
- 压缩包损坏。
- 压缩包条目超限。
- 跨空间迁移部分失败。

错误展示必须包含：

- 用户可理解的原因。
- 当前已完成的安全状态。
- 可重试入口或安全退出入口。
