02 Telemetry & Privacy

03 Model Sovereignty

04 Affective Tensor

05 Memory Architecture

读写分离的三车道架构。Epoch 级去重引擎，分离瞬时情绪与长程记忆。
06 Visual Preservation

拒绝有损压缩。基于 SHA-256 与 pHash 视觉雷达进行影像确权与物理防伪。
