# Pixory v2 Acceptance Criteria

本文档定义 v2 视频、导入、临时查看和跨空间迁移的验收标准。开发完成后，必须按本文件逐项验证。

## 验收环境

至少覆盖：

- Android 模拟器。
- 一台真实 Android 手机。
- 普通空间。
- 隐私空间已设置密码并可解锁。
- 至少一个包含图片、分组、标签、收藏和备注的普通 IP。
- 至少一个包含同名标签的隐私空间数据集。

建议测试素材：

- 小图片 10 张。
- 图片批量导入 100 张。
- 普通视频 1 个。
- 大视频 1 个，建议 1GB 左右。
- `.zip` 图片压缩包 1 个。
- 包含异常文件的 `.zip` 1 个。
- 外部视频文件 1 个。

## 导入页验收

通过标准：

- `选择图片` 只能选择图片。
- `选择视频` 只能选择视频。
- `选择资源包` 只能选择 `.zip` / `.pixorypack`。
- 导入页不显示“复制原图，缩略图单独生成”。
- 导入页不显示“会先解压到 Pixory 私有临时目录”。
- `选择资源包` 仅保留 `支持 .zip / .pixorypack` 这类必要格式提示。
- `当前 IP` 和 IP 名同一行展示。
- IP 名有胶囊、标签、徽标或轻描边等特殊视觉标识。
- `当前 IP` 下方不出现重复解释。
- 分组选项说明不重复。

失败标准：

- 入口文案和可选择文件类型不一致。
- 导入页出现实现细节型长文案。
- IP 名看起来像普通说明文字。

## 大任务进度验收

通过标准：

- 图片批量导入显示进度或真实阶段。
- 视频导入显示进度或真实阶段。
- 压缩包导入显示进度或真实阶段。
- 进度包含当前阶段、总数、成功数、失败数。
- 无字节进度时不显示假百分比。
- 离开导入页面再返回时，任务状态仍可见。
- 大任务运行时仍可浏览已有资产。
- 失败后显示原因和重试入口。

失败标准：

- 大文件操作时界面长时间无反馈。
- 失败后只有泛化错误，没有文件名或阶段信息。
- 离开页面导致任务状态丢失。

## 视频导入验收

通过标准：

- 视频导入后原视频复制到 Pixory 私有 originals。
- 数据库记录包含 mediaType、duration、width、height、mimeType、fileSize。
- 列表显示视频封面、视频标识和时长。
- 封面生成失败时视频记录仍保留，并可重试生成封面。
- 导入失败不会留下成功状态的坏记录。
- 原视频没有被压缩、转码、裁剪、重编码。

失败标准：

- 视频原文件被替换或变小且无明确用户操作。
- 外部 URI 直接登记为正式 original。
- 封面失败导致原视频记录丢失。

## 视频播放器验收

通过标准：

- 本地普通视频可播放。
- 1GB 左右本地视频可播放，打开过程有合理反馈。
- 竖屏可播放。
- 横屏可播放。
- 横竖屏切换不丢播放进度。
- 控制层 3 秒无操作后隐藏。
- 点击视频区域后控制层显示。
- 返回按钮无边框，不使用大卡片样式。
- 右上角三点菜单无边框，不使用大卡片样式。
- 三点菜单可显示 `保存本地` 和 `保存到 IP`。
- 底部只有一排控制。
- 倍速 `0.25x`、`0.5x`、`0.75x`、`1x`、`2x`、`3x` 可选择。
- 不稳定设备上不强行展示 `8x`、`16x`。
- 长按快进可触发，倍数按设置执行。
- 长按视频不会触发保存动作。
- 左右滑动视频区域可拖拽进度。
- 拖拽 UI 跟手。
- 拖拽时显示当前时间。
- 松手后跳转到目标位置。
- seek 不因连续拖拽明显卡死。
- 待播放按钮位于右下角，并与底部控制区齐平。
- 待播放默认不展开。
- 待播放从右下角向上展开。
- 待播放列出当前 IP 下其他视频。
- 点击待播放视频可切换。
- 切换视频后上一条视频停止播放。
- 离开页面后视频暂停并释放。

失败标准：

- 列表页、搜索页、标签页或分组页挂载播放器。
- 拖拽时每次手势都明显触发卡顿 seek。
- 切换视频后上一条声音继续播放。
- 退出页面后视频仍在后台播放。
- 横竖屏切换重置进度。

## 外部视频临时查看验收

通过标准：

- 从系统文件管理器选择视频可用 Pixory 打开。
- 外部视频默认不写正式资产记录。
- 外部视频不进入最近查看、收藏、回收站、备份。
- 右上角三点菜单出现 `保存本地` 和 `保存到 IP`。
- 长按只触发播放器快进，不出现保存入口。
- 保存目标只显示普通模式 IP。
- 不显示隐私空间 IP。
- 选择已有 IP 后走正式视频导入。
- 新建 IP 后走正式视频导入。
- 保存完成后回到原外部视频查看位置。
- 保存完成后只显示完成反馈。
- 不跳首页，不跳 IP 详情。

失败标准：

- 外部 URI 被直接登记为正式 original。
- 保存目标出现隐私空间 IP。
- 保存完成后强制进入应用主页。

## 压缩包临时阅读验收

通过标准：

- 可从系统文件管理器用 Pixory 打开图片 zip。
- 临时阅读不写正式资产记录。
- 临时阅读不进入最近查看、收藏、回收站、备份。
- 不一次性全解压。
- 只缓存当前图片和附近少量图片。
- 左右切换阅读流畅。
- 退出后 session temp 被清理。
- 异常退出后下次启动可清理残留。
- 长按图片出现 `保存到相册` 和 `保存到某个 IP`。
- 保存到 IP 后走正式图片导入。
- 保存到 IP 后不跳主页面。
- 保存完成后显示完成反馈。

安全通过标准：

- zip slip 测试包不能写出 temp 目录。
- 假扩展名图片不能只靠扩展名通过。
- 超大条目或超多条目会被拦截并提示。
- 损坏压缩包会提示失败，不影响正式资产库。

失败标准：

- 打开压缩包时全量解压。
- 临时缓存文件被登记为正式 original。
- 恶意路径写出 Pixory temp 目录。

## IP 跨空间迁移验收

通过标准：

- 普通空间 IP 长按显示 `移入隐私空间`。
- 隐私空间 IP 长按显示 `移出隐私空间`。
- 移入前要求隐私密码校验。
- 未设置隐私密码时先进入设置密码流程。
- 不要求用户每次移入都修改密码。
- 移出必须在隐私空间已解锁时执行。
- 迁移显示进度阶段。
- 迁移后目标空间出现 IP。
- 分组随 IP 复制。
- 图片和视频记录随 IP 复制。
- 原始文件和缩略图复制到目标空间目录。
- 标签按名称复用；目标空间已有同名标签时不重复创建。
- 普通库 tagId 不写入隐私库。
- 迁移失败时源空间数据仍可用。
- 迁移完成前源空间原文件不会被删除。

失败标准：

- 迁移只改字段，没有复制数据库和文件。
- 迁移失败导致源空间和目标空间都不可用。
- 跨库复用源 tagId、groupId、imageId。
- 未校验目标结果就删除源数据。

## 备份和恢复验收

通过标准：

- 备份 manifest 区分 image / video。
- 视频备份包含原视频。
- 图片备份包含原图。
- 恢复前校验 manifest。
- 恢复后图片、视频、标签、分组、备注、收藏状态一致。
- 隐私空间备份和普通空间备份保持隔离。

失败标准：

- 视频备份只有封面，没有原视频。
- 恢复时将 video 当 image 处理。
- 隐私空间数据混入普通备份。

## 搜索和列表验收

通过标准：

- 资产列表可区分图片和视频。
- 视频条目显示封面、播放标识和时长。
- 图片专属筛选不作用于视频。
- 视频不进入图片批量管理。
- 搜索可搜到视频文件名、备注、标签和 IP。
- 搜索结果中视频点击进入视频详情或播放器。

失败标准：

- 视频进入方图、横图、竖图筛选逻辑。
- 视频进入图片批量管理。
- 搜索结果把视频显示成普通图片。

## 数据安全验收

通过标准：

- 导入前后校验文件存在和大小。
- 物理删除只发生在清空回收站或明确清理临时缓存时。
- 缓存清理不触碰 originals。
- 临时查看不污染正式数据库。
- 正式导入不能依赖外部临时 URI。
- 所有大任务失败后保留可诊断状态。

失败标准：

- 原文件被压缩、转码、覆盖或丢失。
- 临时文件被当作正式原文件。
- 清理缓存误删 originals。

## 回归范围

每次 v2 相关改动后至少验证：

- 原图片导入仍可用。
- 图片详情仍可用。
- 图片查看器仍可用。
- 标签、分组、收藏、备注仍可用。
- 回收站恢复和清空仍可用。
- 普通空间和隐私空间切换仍可用。
- 备份功能不回退。
- 搜索不回退。

## 发布前必过

- TypeScript 检查通过。
- 现有测试通过。
- 新增 v2 关键路径测试通过。
- Android release 构建通过。
- 至少一轮 Android 真机手动验收通过。
- 大文件视频播放和导入有实测记录。
