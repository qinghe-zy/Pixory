# Pixory 岁月有声成就系统设计

## Goal

将关于页中“最初的印记”改造成“岁月有声”，以章节式的二级分类和真实可验证的成就记录，展示 Pixory 与用户共同留下的少量重要节点。

## Scope

本轮只改造关于页的数据展示、成就投影、刷新和跳转体验。

保留现有“故事开始”节点及其介绍内容，不将其纳入成就分类。收纳盒、叶子插画、纸张背景和其他主视觉不改。手动“刻入印记”不在本轮实现。

默认仅展示已触发且当前仍有效的二级分类和子条目。点击“岁月有声”后显示分类；点击分类后显示该分类的成就；点击成就进入来源页面或展开验证依据。页面不展示未触发成就，不显示“还差几个”的任务提示，不使用密集表格和日期流水。

新成就使用轻量未读提示，不增加额外文字：

- 新触发且用户尚未查看的二级分类，分类标题左侧显示一个很小、低对比度的圆点。
- 新触发且用户尚未查看的具体成就，成就标题左侧显示同样的小圆点。
- 分类圆点表示该分类下至少有一个未查看成就；展开分类不会自动清除圆点。
- 用户点击具体成就名称后，先展示简短达成条件和发生时间，再将该成就标记为已读；对应圆点消失，分类下没有其他未读成就时分类圆点也消失。
- 点击来源箭头或直接跳转也视为查看该成就，并清除圆点。
- 不使用“已解锁”“完成要求”等长句作为常驻标签。
- 成就条目不使用表情、缩略图或装饰图片；左侧只允许放新成就状态小圆点。
- 成就条目使用稳定的三段式行内排版：`成就名 — 日期 — 跳转箭头`。日期列和右侧操作列使用稳定宽度或布局占位，避免不同标题、日期和是否可跳转导致箭头左右跳动。
- 没有跳转目标的成就仍保留右侧操作列的占位宽度，但不显示箭头；有跳转目标时统一使用同一箭头图标和点击热区。
- 二级分类的展开状态彼此独立；打开一个分类不会自动收起其他已经展开的分类。
- 成就详情采用全页单开状态；点击另一个成就名称时，先关闭当前已展开的成就详情，再打开新的成就详情。
- 点击分类标题只改变该分类的展开状态，不强制关闭其他分类；成就详情只有在点击另一个成就，或离开关于页时关闭。

## Achievement rules

每个成就使用稳定 ID、分类、标题、触发器、发生时间、解锁时间、来源类型和来源 ID。系统只在事实成立且来源可追溯时写入记录。

### 启程

- `first-light`: 首次成功导入并受管保存一张图片或视频；来源为素材 ID；跳转图片/视频详情。
- `first-conversation`: 首个真实 AI 线程产生有效消息；排除空线程、导入占位消息和失败记录；来源为线程 ID 与第一条消息 ID；跳转线程并定位第一条有效消息。

### 心灵触碰

- `deep-night-light`: 本地时间 01:00-04:00，同一线程至少完成 20 轮有效问答；来源为线程 ID 和起点消息 ID；跳转深夜对话。
- `long-conversation`: 一小时内连续完成至少 25 轮有效问答，相邻有效消息间隔不超过 3 分钟；来源为线程 ID、起止消息 ID；跳转长谈起点。
- `memory-note`: 首条记忆进入 active 或用户确认状态；排除 pending、stale、失败和抑制记录；不在关于页显示记忆正文，跳转记忆黑板。
- `memory-grove`: 当前空间存在至少 30 条有效记忆；数字按当前有效记忆重新统计；跳转记忆黑板。
- `private-words`: 首篇角色日记成功生成并保存；排除草稿、失败和取消任务；跳转角色日记。
- `dream-letter`: 首个梦境成功生成并完成用户允许的阅读/保存流程；跳转梦境阅读页。
- `between-two-days`: 对话跨越两个本地日期，属于同一段连续聊天，相邻有效消息间隔不超过 3 分钟，且一小时内连续完成至少 25 轮有效问答；跳转跨日对话起点。
- `week-has-voice`: 连续 7 个自然日都有有效对话，每天至少 3 轮有效问答；跳转对话列表并展示日期范围。

### 时光守候

- `seven-days-poem`: 陪伴天数达到 7 天；展开起始日期、达成日期和计算依据。
- `moon-trace`: 至少在 3 个不同自然月留下有效对话或素材记录；跳转对应记录范围。
- `hundred-day-promise`: 陪伴天数达到 100 天；展开日期计算依据。
- `half-year-date`: 从首次使用日期起满 6 个自然月；展开起止日期和实际天数。
- `one-year-chapter`: 从首次使用日期起满 12 个自然月；展开起止日期和实际天数。
- `four-seasons`: 从首次使用日期开始实际经历春、夏、秋、冬四个季节；展开四季日期并跳转可用记录。
- `new-year-promise`: 12 月 31 日至次年 1 月 1 日期间完成有效对话；跳转对应线程。
- `reunion`: 连续至少 7 天没有有效对话，之后重新完成一轮有效对话；跳转回归后的对话。

### 世界共建

- `parallel-time`: 用户创建分支且分支产生有效消息；跳转分支树并选中对应分支。
- `three-way-crossing`: 同一线程存在至少 3 条有效分支路线；跳转分支树。
- `material-enters`: 首次成功向线程绑定图片、视频、文档或其他本地材料；跳转线程材料区域。
- `paper-sets-sail`: 首个文档或知识库材料成功导入、解析并保存；跳转文档/知识库详情。
- `words-echo`: 首次产生带真实材料引用的 AI 回复；来源为消息和引用记录；跳转消息并展开引用。
- `role-awakens`: 用户对角色卡完成实质配置，至少修改提示、首句、头像、语言或模型偏好一项；跳转角色卡详情。
- `world-grows`: 某个 IP 下拥有至少 30 个未删除图片或视频素材；来源为 IP ID；跳转 IP 详情。
- `three-realms`: 当前空间存在至少 3 个未删除 IP；跳转 IP 总览并显示当前数量。

### 光影整理

- `first-moving-image`: 首次成功导入视频并进入受管存储；跳转视频详情/播放页。
- `kept-treasure`: 首次将图片或视频标记为收藏；跳转对应素材。
- `objects-in-chapter`: 首次创建分组且至少有一份素材成功归入；跳转分组。
- `first-name-tag`: 首次创建标签且成功应用到一份素材；跳转标签结果页。
- `ten-in-one-group`: 同一分组拥有至少 10 个未删除素材；跳转分组详情。
- `hundred-images-scroll`: 当前空间拥有至少 100 个未删除图片或视频素材；跳转全部素材页并显示统计依据。

## Persistence and invalidation

建议新增空间隔离的 `journal_achievements` 表：

```text
id
space
achievementId
category
occurredAt
unlockedAt
readAt
sourceType
sourceId
sourcePayload
createdAt
updatedAt
```

使用 `UNIQUE(space, achievementId)` 保证幂等。

`readAt` 只表示用户是否查看过该成就，不影响成就是否有效。成就因来源失效而隐藏后，关联未读状态一并移除；重新从有效来源触发时创建新的未读状态。

来源变化后，关于页刷新时执行一次轻量有效性投影：

1. 单来源成就先验证来源；失效时寻找下一个满足同一规则的有效来源。
2. 找到替代来源时更新 source、occurredAt 和展示数据。
3. 没有替代来源时隐藏成就，但保留记录以便未来重新触发。
4. 聚合成就重新计算当前数量；不满足阈值时隐藏，重新满足时更新或重新解锁。
5. 线程、IP、素材、记忆被删除后，不允许跳转到错误页面。
6. normal 和 personal 使用独立数据库和独立成就空间。

## Performance

- 关于页首屏只读取页面需要的摘要，不生成完整详单。
- 成就查询按空间聚合，避免每个成就单独查询数据库。
- 触发检测使用必要的索引和限定查询，优先读取计数、最早/最近记录和候选来源。
- `getAppMilestones` 与成就投影尽量共享一次数据库会话。
- 成就投影结果按空间和数据库数据 epoch 短缓存；结构性删除、导入、消息落库、记忆状态变化和 IP/素材变化使对应空间缓存失效。
- `readAt` 只在用户点击成就或其来源入口时写入，不因页面刷新、分类展开或后台投影自动写入。
- 页面刷新只更新数据，不重复播放整页入场动画。
- 展开的分类和子条目使用有界渲染，不在未展开区域挂载全部内容。
- 分类展开集合和当前成就详情 ID 分开维护，避免多个分类展开时成就详情互相错乱。
- 成就行使用固定的标题、日期和操作列，不因详情展开、长标题或缺少跳转目标而改变横向对齐。
- 返回按钮采用固定顶部透明触控区域，不占用白色悬浮卡片空间，不随滚动离开；按下时提供轻微缩放和轻触觉反馈。

## Error handling

- 数据查询失败时保留页面骨架和已缓存的安全摘要，不显示伪造的成就。
- 单个来源失效不影响其他成就。
- 跳转目标失效时显示轻量提示，并立即刷新成就投影。
- 记忆、个人空间和线程目标严格沿用现有空间路由，禁止跨空间跳转。

## Verification

- 为成就规则添加纯函数测试，覆盖时间窗口、连续消息、轮次、阈值和去重。
- 为来源失效添加集成/策略测试，覆盖删除、替代来源、重新统计和隐藏。
- 为路由映射添加测试，覆盖图片、线程、记忆黑板、分支树、IP、文档和角色日记。
- 运行 `pnpm typecheck`、`pnpm test`、`git diff --check`。
- 在 Android 设备或模拟器验证：首屏加载、分类展开、成就跳转、删除后刷新、normal/personal 隔离和返回按钮滚动行为。
